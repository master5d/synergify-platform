# Калькулятор ретрита — движок и формат ссылки

Страница: `academy.synergify.com/instrumenty/kalkulyator-retrita/` (+ `/en/…`). Компоненты —
`components/retreat-calc/`, движок — `engine.ts`, ссылка — `link.ts`.

## Движок (`engine.ts`)

Один движок, два взгляда — ведущий и площадка. Только арифметика: деньги — целые центы, проценты
округляются «половина вверх» к центу, без сети и без LLM.

- Модели контракта с площадкой: `full_campus` (ставка × вместимость — пустые места оплачивает ведущий),
  `per_guest` (ставка × max(гостей, минимум)), `buyout` (взнос + ставка × гостей).
- `compute(inputs)` → честная прибыль, «прибыль, как считает площадка» (выручка − контракт) и разница между
  ними, безубыточность, пустые места, кассовый план по месяцам (месяц 0 — подписание контракта, последний —
  старт) и кассовый разрыв, график платежей площадке и скидка за полную оплату.
- `validate(inputs)` → ошибки с именем поля; `compute` с ошибками бросает исключение, а не возвращает NaN.
- `profitGrid(inputs, prices, guests)` → сетка честной прибыли.

## Ссылка `#data=<base64url JSON>` (версия 1)

Фрагмент ссылки не уходит на сервер; хранения нет. Деньги в ссылке — целые единицы валюты.

```json
{"v":1,"title":"…","currency":"USD","price":2800,"guests":18,"nights":6,"monthsToStart":5,
 "guestDeposit":400,"guestDepositPct":25,"guestBalanceDueDays":45,
 "venue":{"model":"full_campus","ratePerGuest":2000,"capacity":18,"minGuests":0,"buyoutFee":0,
          "depositPct":25,"finalDueDays":45,"payInFullDiscountPct":5,"installments":true}}
```

Обязателен только `v`; остальное необязательно (чего нет — человек вводит на странице). `guestDeposit` (сумма)
важнее `guestDepositPct`. Битая ссылка или другая версия — сообщение на странице и пустая форма.

Пример формы — `fixtures/link-v1.json`, закреплён sha256 в `link.test.ts`. Тот же файл с тем же sha256 лежит у
генератора ссылок (внешний репо): меняешь форму — меняй фикстуру и хэш в обоих местах.
