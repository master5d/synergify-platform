# Анкета гостя ретрита — движок

Страница: `academy.synergify.com/instrumenty/anketa-gostya/` (+ `/en/…`).

Академия анкету не хостит и ответов не хранит (spec подпроекта B, §5.2; слово владельца 2026-10-17 — «ок»).

- `questions.ts` — каталог вопросов: раздел, маршруты (`chef`, `arrivals`, `safety`, `leader`), тип (текст или один
  вариант), тексты RU/EN и короткие подписи для колонок CSV. Имя обязательно и не выключается: по нему сводка
  сводит ответы одного гостя.
  - `formText(on, lang, title)` — текст анкеты для Google Forms, Typeform или письма: разделы, сквозная нумерация,
    варианты в скобках. Перед разделом здоровья — пояснение, зачем вопросы и кто увидит ответы.
  - `answersTemplateCsv(on, lang)` — шаблон таблицы ответов (строка заголовков).
- `answers.ts` — сводка ответов. CSV из сервиса ведущего разбирается в браузере.
  - `matchColumns` узнаёт колонку по тексту вопроса или короткой подписи на любом языке, без регистра, номера и знаков в конце. Не узнанную колонку ведущий выбирает вручную; проблема `missing-column`.
  - `summarize` выдаёт гостей, числа по диетам и «другое» с текстом. Повторная отправка формы схлопывается: остаётся последняя строка (`duplicate-guest`).
  - Ответ вне вариантов помечается `unknown-choice`. На диету такой ответ уходит в «другое», а не в «обычное».
  - Ещё проблемы: `no-emergency`, `severe-allergy`, `more-answers-than-guests`, `no-name`.
  - Выходы: `arrivalsOf` (черновик листа прибытия в колонках таймлайна), `chefToCsv` (питание и аллергии), `safetyToCsv` («важно знать на месте»).
- **Ответы — данные гостей.** Они живут только в памяти страницы и в скачанных CSV. В ссылку и `localStorage` они не попадают. В меню из них уходят только числа по диетам.
- Текст анкеты для гостей — на «вы»: ведущий шлёт его незнакомым людям. Шаблон курса `guest-form.<lang>.md` на «ты» остаётся как есть.
