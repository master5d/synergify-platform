# Реестр практик

`practices.ts` хранит карточки практик ведущего ретрита без привязки к UI. Стартовые карточки берутся из `starter.ts`, а `starterCards(lang)` выбирает язык страницы.

Перед показом карточки можно вызвать `checkCard`: он ловит отсутствие длительности, неполное согласие на касание, отсутствие противопоказаний для высокой нагрузки и обещающие формулировки. Поле `notPromise` предназначено для честных оговорок и намеренно не проверяется.

Реестр экспортируется JSON версии 1. Импорт удаляет неизвестные поля, повторяющиеся id и карточки сверх лимита. `mergeRegistry` добавляет новые карточки после собственных и переименовывает конфликтующие версии.

## Сетка программы

`grid.ts` хранит блоки программы по дням и времени: практики связываются с карточками реестра, а еда создаётся из слотов меню. `checkGrid` проверяет наложения, границы ретрита, нагрузку, свободное время и обязательные поля карточек. `export.ts` выгружает сетку в CSV-шаблон курса с локальным разделителем и строками итогов.

`form.ts` хранит паспорт и блоки конструктора в черновике браузера, а карточки реестра — отдельно.
Ссылка программы содержит только используемые в сетке карточки, поэтому её можно открыть без полного реестра.
При ссылке на соседний инструмент паспорт переносится, а сетка строится заново из его данных.
