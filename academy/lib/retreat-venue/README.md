# Год площадки ретритов

Движок считает модель площадки по 12 месяцам: ретритную и посуточную выручку,
переменные и постоянные расходы, чистый операционный доход, налог, денежный итог
хозяина, доходность и окупаемость.

`computeYear` поддерживает сценарии `as-set`, `nightly-only` и `retreats-only`.
`checkVenue` возвращает проблемы модели по месяцам и затем годовые предупреждения.
Деньги хранятся в целых центах; движок не использует сеть или внешние сервисы.
