# Общее ядро инструментов ведущего

Паспорт ретрита и формат ссылки, общие для калькулятора и инструментов ведущего (таймлайн, дальше — меню, анкета,
конструктор программы).

- `dates.ts` — даты `YYYY-MM-DD`, арифметика только в UTC (`addDays`, `addMonths` с обрезкой до конца месяца,
  `daysBetween`, `monthsBetween`). Локального времени нет: день не сдвигается ни на другом краю света, ни при переводе часов.
- `passport.ts` — `RetreatPassport { title, currency, start, nights, guests, arrivalMeal, departureMeal }`,
  `validatePassport` (ошибки с именем поля), `pickPassport` (allowlist), `passportFromCalcLink` (месяцы до старта из
  ссылки калькулятора → дата старта от сегодняшнего дня).
- `tool-link.ts` — `#data=<base64url JSON>` вида `{ "v": 1, "retreat": {…паспорт}, "tool": {…своё} }`, ключи отсортированы
  (одни данные — одна ссылка). Ссылка калькулятора v1 (без `retreat`) разбирается его `decodeLink` и приходит как `kind: 'calc'`.

**Данные гостей в ссылку не попадают никогда.** Паспорт и поля инструмента читаются по allowlist, всё прочее
отбрасывается (тест подкладывает `phone`, `guests_list`, `arrivals` и проверяет, что их нет). Лист прибытия, ответы
анкеты и всё, что про конкретных людей, живёт только в памяти страницы и в файлах ведущего.
