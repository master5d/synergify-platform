# academy — DESIGN.md

## Что это за интерфейс

Светлая бумага с тёмными полосами-врезками — закрытая школа, не лендинг. Имя гротеском Comfortaa, дисплей Unbounded, текст Onest; золото — точки/ординалы, бронза — ссылки. Дракон — несущий орнамент.

## Решения

- 2026-08-27: контракт заведён миграцией (спек 2026-08-27-design-consolidation); dials выставлены из design/identity.json; палитра дополнена `palette.dark` (`bg`/`accent`) из фактического кода тёмных полос-врезок — `themes/academy.css` (`--bg-invert: #14161a`, `--accent: #d9a95c`, применён на тёмном как `.a-footer-link:hover { color: var(--accent) }`); дескриптор сокращён с 279 до 198 графем, `light`-тема identity.json сохранена как есть.

## Не делать

- Не ставить золото (`#d9a95c`) текстом/ссылками на светлой бумаге — 1.7:1, ниже AA; на светлом для текста и ссылок только бронза `#7a5a18` (5.5:1), золото там — только декор (точки, ординалы, звёзды дракона).
- Не добавлять маркетинговую грамматику лендинга (stats-ряды, таблицы сравнений) на домашнюю страницу — это дом школы, а не лендинг (решение владельца 2026-08-07).
- Не выделять акроним S.A.S.H.A. — нигде, кроме `app/icon.svg`; везде в интерфейсе только полное имя Synergema Authentica Starseed Holon Academy / «школа синергемы».
- Не добавлять переключатель тем / `prefers-color-scheme` — однотемность принципиальна, это внутреннее пространство школы, а не витрина.
- (общелабораторное, не про этот проект) hex в разметке мимо токенов (`lint-design.ps1`)
