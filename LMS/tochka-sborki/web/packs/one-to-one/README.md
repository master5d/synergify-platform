# one-to-one — открытый course-pack

«Один на один и дальше» помогает ведущему разобрать свою практику, отделить метод от себя,
посчитать предел часов и цены и сделать первый шаг к малой группе.

Курс живёт по адресу /odin-na-odin и не учит самой практике или терапии. Он не обещает дохода
или клиентов.

Сборка: COURSE_PACK=one-to-one COURSE_BASE_PATH=/odin-na-odin npm run build

Вклейка в академию: node scripts/merge-course.mjs one-to-one odin-na-odin
