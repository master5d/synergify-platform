# retreat — третий course-pack

«Ретрит с двух сторон» — как провести (ведущий) или принять (площадка) ретрит: общее ядро и два трека ролей.
Честная экономика одной сделки с обеих сторон, договор, отмены и недобор, программа, гости. Курс академии S.A.S.H.A.

## Где живёт

Подпуть школы: `https://academy.synergify.com/retrit` (`COURSE_BASE_PATH=/retrit`, склейка
`scripts/merge-course.mjs` в job `deploy-academy`, после `/praktika`).

## Контракт pack'а (тот же, что у эталона tochka-sborki)

- `course.config.ts` — COURSE; `features` все выключены; `gates` все выключены: курс открыт без входа,
  прогресс копится в браузере и уходит на сервер после логина
- `dictionaries.ts` — полный интерфейс `Dictionary`, значения под курс
- `materials.ts` — шаблоны для практики (`public/retreat-materials/`), пока у курса нет своих инструментов
- `manifest.ts` — исполняемые правила тона: гейтятся только ОБЕЩАЮЩИЕ формы
  (гарантированный доход, «наполним группу», юридическая защита, исцеление)
- `content/{ru,en}/` — шесть модулей: ядро `01`–`02`, трек ведущего `03`–`04`, трек площадки `05`–`06`;
  плюс loose-страницы `cheatsheet/roadmap/exercises`
- `course/*.ts` — форма эталона; `course/companion.ts` — компаньон «Учиться с ИИ» без профиля анкеты
- `skins-meta.ts` + `skins/wanderer.json` — только скин wanderer

## Чего здесь нет (сознательно)

- Выбора роли в движке: пути ролей описаны в контенте (стартовая, roadmap, описания модулей)
- Названий реальных площадок, школ и людей: учебные примеры собраны заново, кейсы — без имён
- Обещаний дохода, полной группы и юридической защиты; нормы закона — с источником и «проверь для своей страны»
