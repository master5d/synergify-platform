<Phase type="activation">

You have an idea — a project, a task, something you've been meaning to start.

Don't picture this as "creating a folder." Picture a bricklayer setting **the first brick in a wall**: no thought of the whole building yet — just this one brick, leveled perfectly, because everything else will follow from it.

Run this in your head: what is your **first brick** right now? Not a plan. Not a list. One moment the movement starts from. **Hold it.**

</Phase>

<Phase type="reflection">

Catch the feeling of giving something important a name — a project, a pet, a character in a game. The moment the name is spoken, it starts shaping the thing.

Don't think of this as "I created AGENTS.md." Picture it as **naming a newborn**: the name doesn't yet reflect anything that will come — but it already sets the character, sets the expectation, sets the direction.

Run it in your head: what are you naming right now? **What name are you giving your project — and what does that name tell the agent about who you are and what you want?**

</Phase>

## AGENTS.md — the agent's project memory

AGENTS.md is a Markdown file with the project's rules and context. It is a shared standard: Codex, Cursor, GitHub Copilot, Antigravity, Hermes and other agents read it on their own when they launch in a folder.

Claude Code has its own file, `CLAUDE.md`. So you don't keep two files, put one line in `CLAUDE.md`: `@AGENTS.md`. It imports `AGENTS.md` in full, which is what the Claude Code docs recommend. You write the rules in one place, and every agent sees them.

### Minimal template

```markdown
# AGENTS.md

## My role
[Who I am, what I know, my experience]

## Project
[What this project is, why it exists]

## Stack
- Node.js 18
- [other tech]

## Folder structure
- `/src` — main code
- `/my-experiments` — experiments

## How to run
[Commands to start]

## What to delegate to the agent
- Writing code from specs
- Tests
- Documentation

## What I decide myself
- Architecture decisions
- Final quality review
```

> 💡 **Ready-made option.** The [student starter](/en/starter/) is this project already assembled: `AGENTS.md` + `CLAUDE.md` with the line `@AGENTS.md`, `TODO.md`, memory between sessions, `my-experiments/`, templates. Works with Claude Code, Codex, Antigravity and Hermes. Building the folder by hand with the steps below is a good path too: you see what it is made of.

### Creating a project

<OsToggle label="Commands for:" />

<OsBlock os="mac">

```bash
mkdir -p ~/my-ai-project
cd ~/my-ai-project
git init
touch AGENTS.md
echo '@AGENTS.md' > CLAUDE.md
mkdir -p src my-experiments
```

</OsBlock>

<OsBlock os="windows">

```powershell
New-Item -ItemType Directory $HOME\my-ai-project -Force
cd $HOME\my-ai-project
git init
ni AGENTS.md -ItemType File
Set-Content CLAUDE.md '@AGENTS.md'
New-Item -ItemType Directory src, my-experiments -Force
```

</OsBlock>

### AGENTS.md tips

- Keep it under **200 lines** — longer drops the quality of instruction-following
- Be specific: `"Use 2-space indent"` beats `"format properly"`
- Update it when architecture or stack changes
- Don't fill in `CLAUDE.md`: it holds only the line `@AGENTS.md`. Anything only Claude Code needs goes below that line
