A good reusable prompt is already almost a Skill.

Don't think of this as "saved text." Picture a locksmith who cut a key to fit one specific lock: it slides in without fumbling, on the first move — no trial and error, no friction. A Skill is that key for your task: `/skill-name`, and the agent opens exactly what's needed.

Notice in your head: which lock in your work is still picked by trial and error every time?

</Phase>

<Phase type="concept">

## What is a Skill

A Skill is a folder with a Markdown file `SKILL.md` inside: instructions that Claude Code runs when you call `/name`. The folder name is the command: folder `meeting-summary/` → `/meeting-summary`.

### SKILL.md structure

```markdown
---
name: meeting-summary
description: Summarizes a meeting from a transcript or notes
---

# Meeting Summary Skill

## Goal
Create a structured meeting recap.

## Instruction
You are a meeting assistant. Based on the provided data:

1. Pull out the main decisions (3–5 bullets)
2. Identify tasks with owners and deadlines
3. Note open questions

## Output format
### Decisions
- [list]

### Tasks
- [ ] [task] — [owner] — [deadline]

### Open questions
- [list]
```

### Where to store Skills

- `~/.claude/skills/` — personal, work across all projects: `~/.claude/skills/<name>/SKILL.md`
- `.claude/skills/` — project-scoped, in git: `.claude/skills/<name>/SKILL.md`

### How to call

```
/meeting-summary [paste transcript or notes]
```

## Plugin vs Skill

| | Plugin | Skill |
|--|--------|-------|
| What | Package with multiple skills | One specific action |
| How to use | Install once | Call via `/name` |
| Example | `firecrawl@local` | `/firecrawl:firecrawl-cli` |

</Phase>

Create a skill for the task from Activation:

<OsBlock os="mac">

```bash
mkdir -p ~/.claude/skills/my-first-skill
touch ~/.claude/skills/my-first-skill/SKILL.md
```

</OsBlock>

<OsBlock os="windows">

```powershell
New-Item -ItemType Directory "$HOME\.claude\skills\my-first-skill" -Force
ni "$HOME\.claude\skills\my-first-skill\SKILL.md" -ItemType File
```

</OsBlock>

Fill out `SKILL.md` using the template above; in the header set `name: my-first-skill` and a `description` — what the skill does and when to call it. Use a real prompt you already have.

Test it:
```
/my-first-skill [give real data]
```

Save the skill file to `my-experiments/u4-my-skill.md`
