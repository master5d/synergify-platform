<Phase type="concept">

## The gateway as conductor

A stack can combine a primary for nuanced work, a floor for offline work, and a fast-path for boilerplate. LiteLLM is the conductor: the agent calls one endpoint while the gateway routes requests in order and switches to fallbacks.

## Honest trade-offs

No stack is "best" — each has its angle:

| Aspect | Claude Code | Sovereign | Cloud-OSS | Behind-GFW |
|---|---|---|---|---|
| **Out-of-box quality** | 9/10 | 7/10 | 7/10 | 6/10 |
| **Setup time** | 5 min | half a day for the learning minimum (local LiteLLM + one local model); full stack — weeks | 30 min | 1 hour |
| **Price/month** | $20+ | $0 + hw | $0–5 | $0 |
| **Privacy** | low | maximum | medium | medium |
| **Speed** | medium | high (local) | variable | very high (Cerebras) |
| **Vendor lock-in (dependence on one provider)** | Anthropic | none | OpenRouter/provider | Cerebras/Google |
| **China access** | needs VPN | works | variable | works |

## Decision tree (if still unsure)

```
Are you in China without VPN?
├── YES → Behind-GFW
└── NO
    │
    Budget $20+/mo and privacy not critical?
    ├── YES → Claude Code
    └── NO
        │
        Have a GPU or Mac M-series?
        ├── YES + autonomy matters → Sovereign
        └── NO → Cloud-OSS
```
