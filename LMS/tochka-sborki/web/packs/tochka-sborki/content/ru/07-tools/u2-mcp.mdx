## MCP: три примитива

| Примитив | Управляется | Что это |
|----------|-------------|---------|
| **Tools** | Моделью | Функции, которые агент вызывает: API-запросы, запись файлов |
| **Resources** | Приложением | Источники данных (как GET-запросы): файлы, записи БД |
| **Prompts** | Пользователем | Шаблоны для оптимального использования |

## Как подключить MCP-сервер

Проще всего — командой в терминале, из папки проекта. Например, официальный сервер поиска Brave:

```bash
claude mcp add --scope project brave-search -- npx -y @brave/brave-search-mcp-server
```

Серверу нужен API-ключ Brave — как его передать, написано в README пакета.

Для других серверов имя пакета бери из их README: имена меняются, актуальное всегда там же. Там же написано, как передать токен. Официальный сервер GitHub — `github/github-mcp-server`: у него есть удалённый адрес `https://api.githubcopilot.com/mcp/` и образ Docker, способ подключения описан в его README. Старые пакеты `@modelcontextprotocol/server-github` и `@modelcontextprotocol/server-brave-search` заархивированы и больше не обновляются.

С `--scope project` Claude Code запишет сервер в файл `.mcp.json` в корне проекта — он общий для команды и лежит в git. Его можно править и руками:

```json
{
  "mcpServers": {
    "brave-search": {
      "command": "npx",
      "args": ["-y", "@brave/brave-search-mcp-server"]
    }
  }
}
```

Личные серверы (scope `user` или `local`) хранятся в `~/.claude.json`. В `.claude/settings.json` MCP-серверы не прописывают — оттуда Claude Code их не читает.

## Популярные MCP-серверы

| Сервер | Что даёт |
|--------|---------|
| `github/github-mcp-server` (официальный, от GitHub) | Issues, PR, commits, файлы репозитория |
| `@modelcontextprotocol/server-filesystem` | Расширенный доступ к файловой системе |
| `@brave/brave-search-mcp-server` (официальный, от Brave) | Поиск в интернете |
| Notion MCP | Чтение и запись страниц Notion |
| Firecrawl | Скрапинг веб-страниц |

## Частые ошибки (~60% проблем)

- `Server transport closed unexpectedly` — синтаксическая ошибка в JSON-конфиге
- Конфликты портов — два сервера пытаются слушать один порт
- Нет переменной окружения — токен не передан правильно

Решение: проверь JSON-синтаксис и токены прежде чем искать глубже.

<Phase type="practice">

Выбери один MCP-сервер из таблицы выше (рекомендую Brave Search или GitHub для старта).

1. Найди его документацию (поиск: `MCP server [название]`) и возьми из README актуальное имя пакета
2. Добавь сервер командой `claude mcp add --scope project <имя> -- npx -y <пакет-сервера>` (или впиши его в `.mcp.json` вручную); для GitHub — как описано в его README: удалённый адрес или Docker, не `npx`
3. Перезапусти Claude Code
4. Проверь что сервер подключился: спроси агента «какие MCP-инструменты доступны?»

Сохрани конфигурацию и результат проверки в `my-experiments/u2-mcp-setup.md`
