## Как сопоставить ограничения и стек

Пять вопросов помогают выбрать путь: бюджет, доступ, железо, приватность и терпимость к настройке. При бюджете $20+ и минимальной настройке подходит Claude Code; при своём железе и автономности — Sovereign; без железа и при малом бюджете — Cloud-OSS; в Китае без VPN — Behind-GFW.

## Почему нельзя «просто Claude Code»

Курс изначально написан под Claude Code — это сильный, удобный инструмент. Но он:

- **Платный** — минимум ~$20/мес на Sonnet
- **Требует доступа** к `claude.ai` и API Anthropic. В Китае без VPN — недоступен
- **Vendor-lock-in** — твои промпты, MCP-конфиги, hooks привязаны к экосисмодуле Anthropic
- **Telemetry (телеметрия, служебные данные об использовании)** — каждый промпт идёт в Anthropic. Не все корпоративные и государственные организации это разрешают

Для большинства студентов это OK. Но если хотя бы один из четырёх пунктов выше — стоп, то Claude Code тебе не подходит. И ты не «хуже» — просто **agentic AI больше не моно-инструмент**, есть открытые альтернативы.

## Что такое «стек»

В контексте этого курса **стек** = комбинация трёх слоёв:

```
┌─────────────────────────────────────────────┐
│  Frontend / Agent UI                        │  ← Claude Code, Cline, Aider, Hermes
├─────────────────────────────────────────────┤
│  Routing / Gateway                          │  ← LiteLLM, OpenRouter, прямой API
├─────────────────────────────────────────────┤
│  Model provider (где живёт интеллект)       │  ← Anthropic, Cerebras, Groq, local GGUF
└─────────────────────────────────────────────┘
```

Каждый слой можно менять независимо. Например:
- **Claude Code → LiteLLM → Cerebras gpt-oss-120b** — Claude Code UI с открытой моделью
- **Aider → прямой OpenRouter → модель DeepSeek** — классический OSS workflow
- **Hermes → LiteLLM с цепочкой запасных моделей** — пример собственного стека

Этот модуль научит тебя **думать про стек целиком**, а не «знать одну тулзу».
