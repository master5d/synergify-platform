## Как сопоставить ограничения и стек

Пять вопросов помогают выбрать путь: бюджет, доступ, железо, приватность и терпимость к настройке. При бюджете $20+ и минимальной настройке подходит Claude Code; при своём железе и автономности — Sovereign; без железа и при малом бюджете — Cloud-OSS; в Китае или России без VPN — Behind-Firewall.

## Почему нельзя «просто Claude Code»

Курс изначально написан под Claude Code — это сильный, удобный инструмент. Но он:

- **Платный** — минимум ~$20/мес на Sonnet
- **Требует доступа** к `claude.ai` и API Anthropic. В Китае без VPN недоступен, в России Anthropic не работает вовсе
- **Vendor-lock-in** — твои промпты, MCP-конфиги, hooks привязаны к экосисмодуле Anthropic
- **Telemetry (телеметрия, служебные данные об использовании)** — каждый промпт идёт в Anthropic. Не все корпоративные и государственные организации это разрешают

Для большинства студентов это OK. Но если хотя бы один из четырёх пунктов выше — стоп, то Claude Code тебе не подходит. И ты не «хуже» — просто **agentic AI больше не моно-инструмент**, есть открытые альтернативы.

## Что такое «стек»

В контексте этого курса **стек** = комбинация трёх слоёв:

```
┌─────────────────────────────────────────────┐
│  Frontend / Agent UI                        │  ← Claude Code, Codex, Hermes, goose, OpenCode
├─────────────────────────────────────────────┤
│  Routing / Gateway                          │  ← LiteLLM, OpenRouter, прямой API
├─────────────────────────────────────────────┤
│  Model provider (где живёт интеллект)       │  ← Anthropic, Cerebras, Groq, local GGUF
└─────────────────────────────────────────────┘
```

Каждый слой можно менять независимо. Например:
- **Claude Code → LiteLLM → Cerebras gpt-oss-120b** — Claude Code UI с открытой моделью
- **Hermes → прямой OpenRouter → модель DeepSeek** — открытый агент обращается к провайдеру напрямую
- **Hermes → LiteLLM с цепочкой запасных моделей** — пример собственного стека

## Обвязка (harness)

Всё, что окружает модель, называют **обвязкой** (англ. harness): инструкции и AGENTS.md, инструменты и MCP, Hooks — проверки вокруг действий агента, память, песочница. Короткая формула: **агент = модель + обвязка**.

У обвязки три рычага:
- **инструкции** — промпт и AGENTS.md (модули 04 и 05);
- **инструменты** — MCP, Skills, доступ к файлам и командам (модуль 07);
- **проверки вокруг вызовов** — Hooks, тесты, лимит шагов (модули 07 и 08).

Обвязка решает не меньше модели. LangChain в феврале 2026 поднял своего агента в Terminal Bench 2.0 с 52,8 до 66,5 %, не меняя модель: поменялись только инструкции, проверки и то, где агент думает дольше. Слои стека выше — тоже часть обвязки: они решают, какую модель и через какой шлюз к моделям получает агент.

Этот модуль научит тебя **думать про стек целиком**, а не «знать одну тулзу».
