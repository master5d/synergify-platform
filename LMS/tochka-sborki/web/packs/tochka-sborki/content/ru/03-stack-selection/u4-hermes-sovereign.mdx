## Режиссёр и worker

Context-saturation возникает, когда один агент пытается держать реализацию целиком. Модель boss-worker разделяет роли: Hermes как boss формулирует подзадачу, запускает worker, получает и проверяет результат, затем обновляет план. Контекст worker'а остаётся атомарным и скоупленным.

## Как это устроено у автора: свой стек на своём железе

В этом юните **Sovereign** означает свой стек: модели на своём железе, данные не уходят к провайдеру, а цепочка запасных вариантов остаётся под твоим контролем. Ниже — не готовый продукт, а принцип устройства такого стека.

```text
Программы автора: Claude Code, Codex и Hermes
                         │
                         ▼
Один шлюз к моделям: LiteLLM на всегда включённом Mac mini
  • программы обращаются в одну точку по алиасам пулов
    (пул = группа взаимозаменяемых моделей под одним именем)
  • ключи провайдеров лежат только на этой машине
  • сначала бесплатные полки провайдеров, локальная ступень — последняя
                         │
             ┌───────────┴───────────┐
             ▼                       ▼
Обычные задачи: облачные       Личные и медицинские данные:
пулы с запасными вариантами     отдельный пул без облачных соседей
             │                       │
             └───────────┬───────────┘
                         ▼
Локальная модель на Mac Studio 128 ГБ
(открытая модель, запущенная локально)

Отдельная машина под Linux — пульт: шлюз и панель наблюдения.
Hermes живёт на отдельной машине под Linux.
```

Примеры маршрута: **Claude Code → LiteLLM → Cerebras gpt-oss-120b** — реальный. **Hermes → LiteLLM с цепочкой запасных вариантов** — тот же принцип: Hermes раздаёт работу исполнителям (Claude Code, Codex), а модели выбирает общий шлюз.

## Что реально ставить

Официальный репозиторий Hermes — [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent). Официальный репозиторий LiteLLM — [BerriAI/litellm](https://github.com/BerriAI/litellm). Установка Hermes и настройка шлюза выполняются по их README; собственного публичного репозитория курса нет, поэтому выдуманные команды установки здесь не приводятся.

Полный стек такого рода — недели работы, не вечер: несколько машин, шлюз, пул моделей, наблюдение, резервные маршруты и правила для чувствительных данных. Курс даёт минимальный опыт: локальный LiteLLM на `localhost:4000` (u3) + одна локальная модель через `llama-server` как последняя ступень + Hermes поверх, по официальным инструкциям.
