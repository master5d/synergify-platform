## Один первый клон: пять типов на карте выбора

Цикл каждого дублёра: **Capture (собрать образцы) → Build (собрать первый вариант) → Test (проверить) → Refine (уточнить)** — поймай образец, собери, проверь на реальной задаче и уточни по результату.

| Клон | Что делает | Экономит |
|------|-----------|----------|
| **Communication (общение)** | Отвечает на письма в твоём стиле | 2–4 ч/день |
| **Meeting Intelligence (разбор встреч)** | Суммирует встречи, пишет задачи | 30 мин/встреча |
| **Content** | Генерирует посты, нарезки, идеи | 5–10 ч/нед |
| **Learning** | Учит тебя новому по расписанию | Качество жизни |
| **Automation** | Pipeline: данные → отчёт, URL → summary | 5–15 ч/нед |

Часы в колонке «Экономит» — ориентир автора, у тебя цифры будут свои.

**Цикл построения:** Capture → Build → Test → Refine.

> 💡 Собери одного клона. Пять типов — это карта выбора, а не обещание построить армию. Модули 06 и 07 покажут, как собрать выбранный вариант технически.
