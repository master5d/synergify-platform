> 💡 **Не только Claude Code.** Файл правил — это паттерн «persistent context file», и у него есть общий стандарт: `AGENTS.md`. Его сами читают Codex, Cursor, GitHub Copilot, Antigravity, Hermes и другие агенты. У Claude Code свой `CLAUDE.md`, поэтому в нём одна строка `@AGENTS.md`: она подключает общий файл. Концепция универсальная: контекст лежит в файле, агент читает его при старте сессии.

<Phase type="activation">

Когда ты начинаешь новую сессию с Claude Code — что ты каждый раз объясняешь заново?

Не думай об этом как об «инструкциях». Представь это как **годовые кольца дерева**: каждый сезон оставляет след прямо в ткани древесины. Засуха, рост, морозы — всё вписано в структуру, не в отдельный архив. Дерево не «помнит» прошлый год — оно им сделано.

Прокрути в голове свою работу с агентом: что из твоего опыта уже «вросло» в структуру проекта? Что пока ещё не закреплено и каждый раз произносится устно, как будто впервые?

</Phase>

<Phase type="reflection">

Каждый раз объяснять одно и то же — это потеря времени и токенов.

Но есть и обратная проблема: AGENTS.md с тысячей строк хуже, чем короткий — до ~200 строк. Чем длиннее — тем хуже агент следует инструкциям.

Не думай об этом как о «коротком конспекте». Представь себя **ткачом у станка**: нить основы натянута чётко и напряжённо — именно это натяжение держит всю ткань. Если добавить слишком много нитей сразу, ткань провиснет, петли запутаются.

Разгляди свою систему памяти: где сейчас натяжение правильное, а где — уже провисает под лишними нитями? Что держит форму, а что разрыхляет структуру?

</Phase>

<Phase type="concept">

## Файлы памяти: три пишешь ты, один — Claude

### AGENTS.md — контекст и правила проекта (главный)

Один файл на всё, что агент должен знать в каждой сессии: кто ты, что за проект, как работать и чего не делать. Его читает любой агент. Claude Code подключает его через `CLAUDE.md` с одной строкой `@AGENTS.md`.

```markdown
# AGENTS.md

## Моя роль
[Профиль, экспертиза]

## Проект
[Что это, зачем нужно]

## Стек
- Node.js 18, TypeScript, React

## Структура
- /src — код
- /tests — тесты

## Как запустить
npm install && npm run dev

## Что делегировать
- Написание кода, тесты, документация

## Что решаю сам
- Архитектура, финальный review

## Правила
- Пиши тесты вместе с кодом
- Перед большой правкой покажи план

## Чего избегать
- Не меняй архитектуру без согласования
```

**Лимит: до ~200 строк.** Больше — хуже следование.

В большом проекте можно положить отдельный `AGENTS.md` в подпапку. В Claude Code он работает вместе с `CLAUDE.md` в той же подпапке (`@AGENTS.md`); Codex читает `AGENTS.md` сам. Для первого проекта хватит одного файла в корне.

### TODO.md — текущие задачи

```markdown
## 🔴 СЕЙЧАС
- [ ] Задача 1 (2 ч)

## 🟡 СЛЕДУЮЩИЕ
- [ ] Задача 2

## ✅ ГОТОВО
- [x] Задача 3
```

### STATE.md — где остановились

Новая сессия начинается с чистого листа. STATE.md возвращает ей картину за минуту. Обновляй его в конце сессии или попроси агента: «сохрани состояние».

```markdown
## Где мы сейчас
[Над чем работаем]

## Что сделано
- …

## Что мешает
- …

## Следующий шаг
[Одно действие]
```

### MEMORY.md — автоматическая память Claude

В отличие от трёх файлов выше, MEMORY.md **пишет Claude сам**.

Что сохраняет: паттерны, исправления, особенности проекта.
Где хранится: `~/.claude/projects/<проект>/memory/MEMORY.md` — только локально.
Управление: `/memory` открывает файлы инструкций; auto-memory живёт в `MEMORY.md` — смотри в документации текущей версии.

Граница простая: что запомнить в MEMORY.md, решает Claude, и видит эту память только Claude на твоём компьютере. Правило, которое должно работать наверняка (например, после исправленной ошибки агента), записывай сам — в AGENTS.md.

Сначала разомнись на разобранном примере.

<FadedExample id="memory-sort"/>

Создай свою систему памяти:

<OsBlock os="mac">

```bash
mkdir -p ~/my-ai-project
cd ~/my-ai-project
touch AGENTS.md TODO.md STATE.md
echo '@AGENTS.md' > CLAUDE.md
```

</OsBlock>

<OsBlock os="windows">

```powershell
New-Item -ItemType Directory $HOME\my-ai-project -Force
cd $HOME\my-ai-project
ni AGENTS.md, TODO.md, STATE.md -ItemType File
Set-Content CLAUDE.md '@AGENTS.md'
```

</OsBlock>

Заполни AGENTS.md по шаблону выше — используй реальный проект или задачу из своей работы. Или попроси агента создать эти файлы.

Добавь в TODO.md хотя бы 3 задачи, которые у тебя реально есть прямо сейчас.

Запусти Claude Code и проверь: `«Что ты знаешь о моём проекте?»`

Сохрани ответ в `my-experiments/u3-memory-test.md`

</Phase>
