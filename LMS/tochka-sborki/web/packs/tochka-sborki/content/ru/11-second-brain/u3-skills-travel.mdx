## «Мой агент учит твоего» — по-честному

Можно собрать общий чат, где один агент показывает другому, как работать. Выглядит как обучение, но **веса модели при этом не меняются**.

Никакого дообучения из модуля [10](/lessons/10-model-training/) здесь нет. Передаётся текст: папка Skill, шаблон правил, примеры. Твой агент читает эти файлы и начинает работать иначе.

Отсюда простое следствие. Skill живёт, пока файлы лежат у тебя. Удалил папку — Skill ушёл. Поправил файл — Skill изменился сразу, без прогонов и видеокарт.

## Skill — это папка

Ты уже делал Skill в модуле [07](/lessons/07-tools/u4-skills/). Напомним устройство:

```
meeting-summary/
├── SKILL.md       # обязательно: name, description и инструкция
├── scripts/       # по желанию: исполняемый код
└── references/    # по желанию: справочные файлы
```

Этот формат — открытый стандарт [Agent Skills](https://agentskills.io). Его создала Anthropic и открыла для всех. Тот же формат читают Claude Code, Codex, Gemini CLI, Cursor, GitHub Copilot и другие агенты.

Значит, **Skill, собранный для одного агента, часто подходит и другому**.

## Три способа передать Skill

1. **Скопировать папку.** Личные Skills — в `~/.claude/skills/<имя>/`, Skills проекта — в `.claude/skills/<имя>/`.
2. **Общий репозиторий.** Автор выкладывает Skills в открытый git-репозиторий. Ты клонируешь его в отдельную папку, читаешь и копируешь к себе только нужное. Обновления приходят через `git pull` — и их тоже читаешь.
3. **Плагин.** Пакет, который ставится через `/plugin install` (модуль 07). Кроме Skillов, в нём могут быть hooks и MCP-серверы, то есть исполняемый код.

Многие авторы выкладывают свои Skills открыто. Пример — репозиторий [anthropics/skills](https://github.com/anthropics/skills). Большинство Skillов там под лицензией Apache 2.0, а Skills для документов (docx, pdf, pptx, xlsx) открыты только для чтения. Сами авторы называют их примерами и советуют сначала проверить Skill у себя.

## Что передаётся, а что нет

**Передаётся:** Skills, шаблоны `AGENTS.md`, чек-листы, примеры хороших ответов.

**Не передаётся:** личная память — ни твоя, ни чужая — и ключи. Архив у каждого свой.

Чужие правила не копируй целиком. Возьми идею и перескажи её под свой проект.

## Как агент перенимает Skill из разговора

Есть и обратный путь: агент сам оформляет Skill из удачной работы. Сделали с агентом задачу хорошо — попроси:

```
Сохрани то, что мы сейчас сделали, как навык в .claude/skills/.
Покажи мне SKILL.md до того, как сохранять.
```

Так же можно перенять увиденное у другого. Опиши своими словами, что делает чужой агент, — твой оформит это в Skill. Ты читаешь и правишь.

Навык: [имя, откуда взят — ссылка]

Есть ли исполняемый код (scripts/): [да / нет — что он делает]

Что осталось непонятным: [...]
