<Phase type="activation">

Представь вечер через месяц. Ты в дороге, пишешь боту с телефона: «Что я решил по переезду и почему?»

Через минуту приходит ответ — с именами заметок, из которых он собран. Всё это работает на твоём компьютере, в твоих файлах, без новой подписки.

Какой кусок этой картины у тебя уже есть, а какого пока не хватает?

</Phase>

<Phase type="reflection">

Полный второй мозг сразу не нужен. Нужен минимальный, но рабочий: одна память, один канал, один навык.

Сколько уйдёт времени, заранее не скажет никто. У кого-то сборка займёт вечер, у кого-то несколько вечеров — зависит от опыта и от того, что уже стоит. Оба варианта нормальные.

Подумай, что для тебя будет знаком «работает»: какой вопрос с телефона должен получить правильный ответ?

</Phase>

<Phase type="concept">

## План сборки

Теперь **соединяем заготовки из юнитов 1–4 в минимальный рабочий второй мозг**.

**1. Память.** Проект из модуля 05 или стартер. В нём `notes/` с настоящими заметками и блоки «Второй мозг» и «Входящие сообщения» в `AGENTS.md`.

**2. Канал.** Сначала fakechat, потом — если хочешь — Telegram по [документации Channels](https://code.claude.com/docs/en/channels). Список разрешённых — только ты. Токен — в `.env` канала, не в проекте.

**3. Навык.** Один чужой навык — тот, что ты разобрал в юните 3. Пройди по нему правило 1 из юнита 4. Всё понятно — копируй в `.claude/skills/<имя>/` своего проекта. Что-то непонятно — возьми другой навык или собери свой по разговору.

**4. Три проверки.**

- **Архив:** вопрос через канал — ответ с адресами файлов, адреса сходятся.
- **Дверь:** попроси друга написать твоему боту. Ответа быть не должно. Для fakechat эта проверка не нужна: он открыт только на твоём компьютере.
- **Канарейка:** тест из юнита 4 — файл не удаляется без твоего подтверждения.

**5. Копия.** Сохрани второй мозг в git. Перед первым коммитом проверь, что в файлах нет токенов и паролей, а `.env` указан в `.gitignore`.

```bash
git init
git status
git add AGENTS.md CLAUDE.md STATE.md TODO.md .gitignore notes .claude/skills
git status
git commit -m "второй мозг: память, правила, первый навык"
```

Добавляй файлы по именам, как здесь, а не всё разом: так случайный секрет не уедет в историю. Оставь в списке только то, что у тебя есть: если одного пути нет, git не добавит ничего. Папки `notes` и `.claude/skills` уходят целиком, поэтому перед коммитом ещё раз посмотри `git status`.

## Вместе с другими

Второй мозг — личный, а учиться собирать его проще рядом с другими. Покажи результат в сообществе курса: что работает, что нет. Ключи, токены и заметки не выкладывай.

Так и выглядит «мой агент учит твоего» в честной форме. Вы делитесь навыками-папками через открытые репозитории. Каждый читает навык до установки. Память у каждого остаётся своя.

Для памяти и навыков докупать ничего не нужно: это твои файлы, и с ними работает любой агент. С каналом честнее так: каналы из юнита 2 — возможность Claude Code. Если твой агент другой (Codex, локальная модель), ищи его собственный шлюз в мессенджер в его документации — как у Hermes и OpenClaw.

<Phase type="practice">

Собери минимальный второй мозг по плану выше. Затем сохрани отчёт в `my-experiments/u5-second-brain.md`:

```
# Мой второй мозг

## Память
Папка проекта: [путь]
Заметок в notes/: [число]
Блоки в AGENTS.md: [Второй мозг / Входящие сообщения]

## Канал
Какой: [fakechat / Telegram / другой]
Кто в списке разрешённых: [...]
Где токен: [путь, НЕ сам токен]

## Навык
Имя и источник: [...]
Прочитан целиком, включая scripts/: [да]
Что делает у меня: [...]

## Проверки
Архив отвечает с адресами: [да / нет — что не так]
Чужое сообщение без ответа: [да / нет / не применимо для fakechat]
Канарейку без моего подтверждения не удалили: [да / нет — какой слой сработал]

## Копия
Коммит без секретов: [да — хэш коммита]

## Следующий шаг
[что добавлю в следующий раз: второй навык, почта, ...]
```

Если какая-то проверка не прошла — это тоже результат. Отметь, что сломалось, и вернись к нужному юниту.

</Phase>
