## Как устроен канал

Сообщение идёт из мессенджера до сессии агента на твоём компьютере и обратно:

```
ты в мессенджере → бот → плагин-канал → запущенная сессия агента → твои файлы
                                                  ↓
ты в мессенджере ← бот ← ответ агента ←───────────┘
```

Три важных свойства:

- **Работа идёт у тебя.** Агент отвечает из сессии на твоём компьютере и работает с настоящими файлами. Облако мессенджера только передаёт текст.
- **Сессия должна быть открыта.** Нет запущенной сессии — некому ответить. Для постоянной связи агента держат в отдельном окне терминала или в фоновом процессе.
- **Бот — это адрес.** Каждый, кто знает имя бота, может ему написать. Поэтому нужен список разрешённых отправителей.

## Каналы в Claude Code

У Claude Code для этого есть **Channels** — [официальная документация](https://code.claude.com/docs/en/channels). Сейчас это research preview: набор каналов и синтаксис команд могут меняться. Поэтому шаги ниже — пересказ документации, а первоисточник всегда главнее.

В preview входят Telegram, Discord и iMessage. Каждый канал — плагин из официального маркетплейса. Для работы плагинов нужен [Bun](https://bun.sh).

**Репетиция без внешних сервисов — fakechat.** Это демо-канал: чат в браузере на твоём компьютере, без ботов и токенов.

```
/plugin install fakechat@claude-plugins-official
```

Затем выйди из Claude Code и запусти его заново с каналом:

```bash
claude --channels plugin:fakechat@claude-plugins-official
```

Открой `http://localhost:8787`, отправь сообщение — оно придёт в твою сессию, а ответ вернётся в браузер.

**Telegram — по шагам документации:**

1. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot`, получи токен бота.
2. В Claude Code: `/plugin install telegram@claude-plugins-official`.
3. Сохрани токен: `/telegram:configure <токен>`. Он ляжет в `~/.claude/channels/telegram/.env` — вне проекта и вне git.
4. Перезапусти: `claude --channels plugin:telegram@claude-plugins-official`.
5. Напиши боту — он пришлёт код привязки. В Claude Code: `/telegram:access pair <код>`.
6. Закрой дверь для остальных: `/telegram:access policy allowlist`.

После шестого шага сообщения от чужих аккаунтов молча отбрасываются. Этот шаг не пропускай.

## Почта и другие агенты

**Почта** обычно подключается иначе: через MCP-сервер почтового сервиса (модуль [07](/lessons/07-tools/)). Агент читает письма, когда ты его просишь, а не получает их сам.

Учти: написать тебе письмо может кто угодно в мире. Список разрешённых отправителей здесь не встроен.

**Другие агенты** — Hermes, OpenClaw и похожие — умеют жить в мессенджерах через свои шлюзы. Схема та же: бот, разрешённые отправители, работа на твоей машине. Команды смотри в их документации.

## Когда ты не у терминала

Если агенту нужно твоё разрешение на действие, сессия ждёт ответа. Документация упоминает режим, который пропускает такие вопросы. Для агента, до которого можно достучаться снаружи, мы его не включаем — почему, разберём в юните 4.
