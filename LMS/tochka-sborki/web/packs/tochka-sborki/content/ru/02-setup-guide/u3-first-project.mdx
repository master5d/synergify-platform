<Phase type="activation">

У тебя есть идея — проект, задача, что-то, что давно хотелось сделать.

Не представляй это как «создание папки». Представь, как каменщик кладёт **первый кирпич в кладке**. Он не думает о всём доме сразу — он выравнивает только этот один, потому что именно от него пойдёт всё остальное.

Прокрути в голове: что у тебя сейчас **первый кирпич**? Не план. Не список. Один момент, с которого начнётся движение. **Удержи его.**

</Phase>

<Phase type="reflection">

Вспомни, как ты давал имя чему-то важному — проекту, питомцу, персонажу в игре. В момент, когда имя произнесено, — оно начинает определять форму.

Не думай об этом как «я создал AGENTS.md». Представь, как **называют новорождённого**: имя ещё не отражает ничего, что будет, — но уже задаёт характер, задаёт ожидание, задаёт вектор.

Прокрути в голове: что ты сейчас «называешь»? **Какое имя даёшь своему проекту — и что это имя говорит агенту о том, кто ты и чего хочешь?**

</Phase>

## AGENTS.md — память агента о проекте

AGENTS.md — это Markdown-файл с правилами и контекстом проекта. Это общий стандарт: Codex, Cursor, GitHub Copilot, Antigravity, Hermes и другие агенты читают его сами при запуске в папке.

Claude Code читает `AGENTS.md` сам — без импорта и настроек — начиная с версии 2.1.277; для всех его режимов курс требует версию не ниже 2.1.281. Проверь её командой `claude --version`. Правила пишешь в одном месте, и видит их любой агент.

### Минимальный шаблон

```markdown
# AGENTS.md

## Моя роль
[Кто я, что я знаю, мой опыт]

## Проект
[Что это за проект, зачем нужен]

## Стек
- Node.js 22+ (только для npm-установки; native installer Node.js не требует)
- [другие технологии]

## Структура папок
- `/my-experiments` — эксперименты

## Как запустить
[Команды для старта]

## Что делегировать агенту
- Написание результата по твоему техническому заданию (ТЗ)
- Тесты
- Документирование

## Что решаю сам
- Архитектурные решения
- Финальная проверка качества
```

> 💡 **Готовый вариант.** [Стартер студента](/starter/) — это такой проект, уже собранный: `AGENTS.md`, `TODO.md`, память между сессиями, `my-experiments/`, шаблоны. Работает с Claude Code, Codex, Antigravity и Hermes. Собрать папку руками по шагам ниже — тоже хороший путь: так видно, из чего она состоит.

### Создание проекта

<OsToggle />

<OsBlock os="mac">

```bash
mkdir -p ~/my-ai-project
cd ~/my-ai-project
git init
touch AGENTS.md
mkdir -p my-experiments
```

</OsBlock>

<OsBlock os="windows">

```powershell
New-Item -ItemType Directory $HOME\my-ai-project -Force
cd $HOME\my-ai-project
git init
ni AGENTS.md -ItemType File
New-Item -ItemType Directory my-experiments -Force
```

</OsBlock>

### Советы по AGENTS.md

- Держи до **200 строк** — длиннее снижает качество следования инструкциям
- Будь конкретным: `«Используй 2-пробельный отступ»` лучше чем `«форматируй правильно»`
- Обновляй когда меняется архитектура или стек
- Для Claude Code используй версию не ниже 2.1.281. Выполни `/memory`: в списке должен быть путь к `AGENTS.md`. Если в папке проекта или выше есть `CLAUDE.md` либо `CLAUDE.local.md`, Claude Code молча пропустит `AGENTS.md`; убери такой файл из этой цепочки.

<Phase type="practice">

Создай свой первый проект:

<OsBlock os="mac">

```bash
mkdir -p ~/my-ai-project
cd ~/my-ai-project
git init
touch AGENTS.md
mkdir -p my-experiments
```

</OsBlock>

<OsBlock os="windows">

```powershell
New-Item -ItemType Directory $HOME\my-ai-project -Force
cd $HOME\my-ai-project
git init
ni AGENTS.md -ItemType File
New-Item -ItemType Directory my-experiments -Force
```

</OsBlock>

Заполни AGENTS.md по шаблону — напиши про реальный проект или задачу, над которой хочешь работать.

Затем запусти Claude Code в этой папке:

```bash
claude
```

Выполни `/memory`: в списке должен быть путь к `AGENTS.md`. Затем задай агенту: `«Прочитай правила проекта и скажи, что ты теперь знаешь о проекте»`

Сохрани результат в `my-experiments/u3-claude-reads-context.md`
