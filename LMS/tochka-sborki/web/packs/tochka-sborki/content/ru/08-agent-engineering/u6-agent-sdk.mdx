<Phase type="activation">

Представь не чат, а маленькую мастерскую, которую ты можешь вызвать из своей программы. У неё есть руки — инструменты, память — сессия, и правило остановки — чтобы работа не продолжалась бесконечно.

Если ты уже знаешь, что агент должен делать снова и снова, но каждый запуск всё ещё начинаешь вручную, где ему не хватает одной кнопки «старт»?

</Phase>

<Phase type="reflection">

Agent SDK превращает агентный loop в библиотечный вызов. Claude Code остаётся тем же механизмом: агент планирует шаги, вызывает инструменты и проверяет результат, а твой скрипт задаёт границы и получает сообщения.

Это похоже на передачу мастерской по расписанию: ты не пишешь заново, как пользоваться каждым инструментом, но решаешь, какие инструменты лежат на столе и когда мастер обязан остановиться.

Для разовой интерактивной задачи оставь Claude Code CLI. SDK нужен, когда агент становится частью CI/CD, приложения или постоянной автоматизации.

</Phase>

<Phase type="concept">

## Что входит в SDK

Agent SDK даёт тот же loop, что и Claude Code, но из Python или TypeScript: встроенные `Read`, `Edit`, `Bash`, `Grep`, `Glob` и веб-поиск, MCP-серверы, hooks, skills, субагентов и сессии. В клиентском SDK tool loop и файловые инструменты пришлось бы собирать самому.

Установка:

```bash
npm install @anthropic-ai/claude-agent-sdk   # Node 18+
pip install claude-agent-sdk                 # Python 3.10+
```

Авторизация — две дороги, как в [модуле 02](/lessons/02-setup-guide/u2-install/). Для себя SDK работает через тот же вход, что и Claude Code (`claude login`, подписка): переменная `ANTHROPIC_API_KEY` должна быть не установлена, иначе SDK пойдёт по ключу и начнёт списывать токены. Для продукта, клиента или production-автоматизации официальный quickstart описывает `ANTHROPIC_API_KEY` — ключ клиента, не твоя подписка. Ключ не клади в репозиторий и не печатай в логе; условия тарифа меняются, перед запуском проверь актуальную документацию.

Минимальный TypeScript-агент:

```ts
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Найди и исправь баг в auth.py",
  options: {
    allowedTools: ["Read", "Edit", "Bash"],
    permissionMode: "acceptEdits",
    maxTurns: 10,
  },
})) {
  if ("result" in message) console.log(message.result);
}
```

## Три ручки безопасности

- `allowedTools` — белый список. Начни с минимума: для анализа достаточно `Read`, `Glob`, `Grep`.
- `permissionMode` — уровень согласия: `default` спрашивает, `acceptEdits` пропускает правки, а `bypassPermissions` допустим только внутри изолированного контейнера. Подробная таблица — см. шпаргалку.
- `maxTurns` — потолок итераций, который не даёт агенту зациклиться. Для типичной задачи начни с 10–20, а для диагностики поставь меньше.

`cwd`, `mcpServers`, `hooks`, `agents`, `resume` и `settingSources: ["project"]` добавляют рабочую папку, внешние инструменты, специалистов, продолжение сессии и проектные настройки. Один агент — одна задача; универсальный агент с десятками инструментов дорог и плохо управляем. Субагент не должен запускать собственных субагентов. Три субагента — примерно три раза больше вызовов, поэтому дешёвую модель используй там, где она справляется.

Для запуска подходят четыре схемы: эфемерный контейнер на задачу, долгоживущий процесс, гибрид с загрузкой истории или несколько процессов в одном контейнере. В любом варианте закладывай исходящий HTTPS и минимальные ресурсы; главная статья расходов обычно токены.

<Phase type="practice">

Собери маленький эксперимент в отдельной папке.

1. Установи SDK для своего языка.
2. Запусти тест с `maxTurns: 1` и промптом: `Скажи «SDK работает!» и больше ничего.` Запиши, сколько ходов действительно произошло.
3. Запусти project-analyzer с `allowedTools: ["Read", "Glob", "Grep"]`, `permissionMode: "default"` и `maxTurns: 5`. Попроси его описать структуру проекта, не менять файлы и не выполнять команды.
4. Сохрани в `my-experiments/u6-agent-sdk.md` ответы: сколько было ходов, какие инструменты вызваны и что ты изменил бы в промпте.

Если агент просит лишний инструмент, не добавляй его автоматически: сначала уточни задачу и проверь, можно ли решить её меньшими правами.

</Phase>
