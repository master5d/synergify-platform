## Основа практики — smol-course

Практика собрана по мотивам [smol-course](https://github.com/huggingface/smol-course) от Hugging Face (лицензия Apache-2.0). Здесь — сокращённый пересказ на русском с нашими изменениями, первоисточник всегда главнее.

Одна оговорка. Текущая версия курса строится на более крупной SmolLM3; часть упражнений рассчитана на инфраструктуру Hugging Face. Нам нужна архивная версия **v1** в том же репозитории: там упражнения на SmolLM2 с кнопкой запуска в Colab.

- `v1/1_instruction_tuning/notebooks/sft_finetuning_example.ipynb` — SFT на SmolLM2.
- `v1/3_parameter_efficient_finetuning/notebooks` — `finetune_sft_peft.ipynb` (LoRA) и `load_lora_adapter.ipynb` (как загрузить адаптер).
- `v1/4_evaluation` — как устроена оценка.

Теорию по трансформерам и библиотекам глубже даёт [LLM Course](https://huggingface.co/learn/llm-course) Hugging Face (репозиторий `huggingface/course`, Apache-2.0).

Для тех, кто хочет понять, как обучают модели с нуля, у Hugging Face есть [The Smol Training Playbook](https://huggingface.co/spaces/HuggingFaceTB/smol-training-playbook). Лицензия у него не указана, поэтому мы только ссылаемся на него и не пересказываем.

## Где взять видеокарту бесплатно

- **Google Colab** или **Kaggle Notebooks** — бесплатные GPU в браузере. Лимиты и доступность меняются и не гарантированы — проверь условия на месте.
- **Своё железо** — любая видеокарта с CUDA или Mac с Apple Silicon. Модель на 135M параметров скромна по памяти; прогон на CPU тоже возможен, но медленный.

Платный облачный тюнинг здесь не нужен: задача практики — пройти цикл целиком, а не выжать рекорд.

## Пять шагов прогона

**1. Данные.** Собери примеры в файл `train.jsonl` (jsonl — по одному JSON на строку), в формате, который понимает TRL:

```json
{"messages": [{"role": "user", "content": "запрос"}, {"role": "assistant", "content": "желаемый ответ"}]}
```

Holdout из юнита 4 держи в отдельном файле. В обучение он не попадает.

**2. Замер «до».** Прогони holdout через исходную модель и сохрани ответы:

```python
from transformers import pipeline

pipe = pipeline("text-generation", model="HuggingFaceTB/SmolLM2-135M-Instruct")
out = pipe([{"role": "user", "content": "запрос из holdout"}], max_new_tokens=200)
print(out[0]["generated_text"])
```

**3. Обучение с LoRA.** Скелет по документации TRL — перед запуском сверь его с ноутбуком `finetune_sft_peft.ipynb`, API библиотек меняется:

```python
from datasets import load_dataset
from peft import LoraConfig
from trl import SFTConfig, SFTTrainer

train = load_dataset("json", data_files="train.jsonl", split="train")

trainer = SFTTrainer(
    model="HuggingFaceTB/SmolLM2-135M-Instruct",
    train_dataset=train,
    args=SFTConfig(output_dir="smollm2-my-task", learning_rate=1e-4),
    peft_config=LoraConfig(),
)
trainer.train()
trainer.save_model()
```

Если тренер ругается на формат чисел (bf16 — компактный формат чисел, не все карты умеют) на старой видеокарте — возьми настройки из ноутбука курса, они подобраны под Colab. `learning_rate` — скорость обучения, бери из ноутбука.

**4. Замер «после».** Загрузи адаптер по `load_lora_adapter.ipynb` и прогони тот же holdout с теми же запросами.

**5. Сравнение.** Сверь ответы «до» и «после» по критериям из юнита 4. Добавь дешёвую альтернативу: исходную модель с хорошим промптом.
