# my-experiments

Твоя песочница. Практики курса просят сохранять сюда результат — под именем, которое
назвал урок, например `u3-memory-test.md` (модуль 05, урок 3) или `u6-pendel.md` (модуль 07, урок 6).

Имена в уроках начинаются с номера урока, а номер модуля в них не пишется. Если два файла
из разных модулей совпали по имени, добавь номер модуля в начало: `05-u3-memory-test.md`.

Скриншоты (`.png`) тоже клади сюда. Свои эксперименты вне курса называй `experiment-<тема>.md`.

Хороший результат, который хочется повторить, переноси в `../my-templates/`.
