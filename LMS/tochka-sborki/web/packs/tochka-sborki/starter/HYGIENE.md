# Гигиена проекта — чек-лист

Пройди раз в месяц или когда работать с агентом стало тяжелее. Полный аудит агентом и
промпт для него — в практике «Пендель» (урок 07/u6). Правило оттуда: из найденного
чинишь **три** пункта, по одному, с коммитом после каждого; остальное — в `TODO.md`.

Перед началом: `git status` должен быть чистым.

## 1. Размер файлов и монолиты
- [ ] Нет файлов, в которых смешано несколько обязанностей (логика, разметка, стили в одном)
- [ ] Самые длинные файлы проекта ты знаешь и понимаешь, почему они такие

## 2. Смешанные слои
- [ ] Стили и скрипты лежат отдельно, а не внутри HTML или шаблонов

## 3. Настройки агента
- [ ] В `.claude/settings.json`, `.codex/`, конфиге MCP нет устаревших разрешений и дублей
- [ ] Нет абсолютных путей к чужим папкам
- [ ] Нет ключей и токенов в открытом виде — только в `.env`

## 4. Файл правил
- [ ] `AGENTS.md` короче ~200 строк
- [ ] В нём нет противоречий и устаревших инструкций
- [ ] `CLAUDE.md` по-прежнему только подключает `AGENTS.md`

## 5. Память между сессиями
- [ ] `STATE.md` обновлялся после последней рабочей сессии
- [ ] По `STATE.md` и `TODO.md` новая сессия понимает, что сделано и что дальше

## 6. Hooks
- [ ] Ты знаешь, что делает каждый hook проекта (hook запускает команду на твоём компьютере)
- [ ] Hooks, которые больше не нужны, удалены

## 7. Git
- [ ] `.env` и личные настройки агента не попали в git: в выводе `git ls-files` их нет
- [ ] Последний коммит не старше последней рабочей сессии
