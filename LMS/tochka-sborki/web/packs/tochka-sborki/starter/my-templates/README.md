# my-templates

Библиотека того, что **работает**: промпты и шаблоны, которые уже дали хороший результат.
Экспериментальное — в `../my-experiments/`, сюда переносишь проверенное.

Уже лежат (те же файлы, что в материалах курса):

| Файл | Что это |
|------|---------|
| `agent-charter.md` | Устав агента — заготовка system-промпта для твоего ИИ-напарника |
| `automation-recipes.md` | Рецепты агентных автоматизаций |
| `feedback-template.md` | Отзыв после модуля: копируй в `my-experiments/feedback-m<N>.md` |
| `feedback-final-jtbd.md` | Итоговый отзыв о курсе: копируй в `my-experiments/feedback-final.md` |

`prompt-post-from-notes.md`. Шаблон изменился — сохрани старую версию рядом (`-v1.md`).
