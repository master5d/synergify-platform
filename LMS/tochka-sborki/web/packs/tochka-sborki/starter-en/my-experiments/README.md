# my-experiments

Your sandbox. Course practices ask you to save the result here, under the name the lesson
gives, for example `u3-memory-test.md` (module 05, lesson 3) or `u6-pendel.md` (module 07, lesson 6).

Names in the lessons start with the lesson number; the module number is not part of them. If two files
from different modules end up with the same name, put the module number in front: `05-u3-memory-test.md`.

Screenshots (`.png`) go here too. Name your own experiments outside the course `experiment-<topic>.md`.

A good result you want to repeat moves to `../my-templates/`.
