# my-templates

A library of what **works**: prompts and templates that have already given a good result.
Experimental things go to `../my-experiments/`; you move the proven ones here.

Already inside (the same files as in the course materials):

| File | What it is |
|------|------------|
| `agent-charter.md` | Agent charter: a system-prompt skeleton for your AI partner |
| `automation-recipes.md` | Agentic automation recipes |
| `feedback-template.md` | Feedback after a module: copy it to `my-experiments/feedback-m<N>.md` |
| `feedback-final-jtbd.md` | Final course feedback: copy it to `my-experiments/feedback-final.md` |

Name your own template by answering "when do I use this?": `prompt-email-client-delay.md`,
`prompt-post-from-notes.md`. If a template changes, keep the old version next to it (`-v1.md`).
