# living-practice — второй course-pack

«Практика в живой связи» — шесть уроков о том, почему честной практике внимания
нужны другие люди. Контент — проза курса академии
(`academy/lib/course/living-practice.ts`), перенесённая в формат LMS-движка.

## Зачем этот pack

Второй жилец движка: доказывает, что `COURSE_PACK=<slug>` действительно собирает
другой сайт из тех же компонентов. Сайт НЕ деплоится — в `LMS/registry.json`
курс стоит как `coming-soon`; домен `https://praktika.synergify.com` контрактный.

## Контракт pack'а (тот же, что у эталона tochka-sborki)

- `course.config.ts` — COURSE (name/fullName/domain/locales)
- `dictionaries.ts` — полный интерфейс `Dictionary`, значения под курс практики
- `materials.ts` — минимальный честный манифест (ссылки на академию)
- `content/{ru,en}/01-living-practice/` — один модуль, 6 юнитов, чистая проза
  (без Phase-компонентов); плюс loose-страницы `cheatsheet/roadmap/exercises`
  (нужны маршрутам движка, содержат честные заглушки)
- `course/*.ts` ×11 — форма эталона, данные минимальные/тёмные
- `skins-meta.ts` + `skins/wanderer.json` — только скин wanderer

## Чего здесь нет (сознательно)

- Реальных кейсов, showcase-видео, дримов — массивы пустые, движок рендерит тёмным
- RPG-глубины: скин один (wanderer), dungeon-флейворы нейтральные
- Обещаний результата: копия де-hustle; курс не заменяет терапию и говорит это вслух
