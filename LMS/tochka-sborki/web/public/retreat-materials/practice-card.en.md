# Practice card

One card is one practice. The guest, the venue and you yourself read it when you build the grid of days.

| Field | What to write |
|---|---|
| Name | What you call the practice. |
| Format | Group, pair or solo. |
| Duration for the group | How many minutes the practice takes for the whole group, not for one pair. |
| Load | Low, medium or high: breath, movement, emotions. |
| Contraindications | When the practice is skipped or done lightly. The decision stays with the guest and their doctor. |
| Touch | Yes or no. If yes — how you ask for consent and how a guest can decline. |
| What it needs | A hall, mats, blankets, music, open space. Who brings what: venue / leader / guest. Scent, smoke, loud sound — yes or no, how to opt out. |
| What the practice does not promise | One honest sentence: no "it will heal" and no "it unlocks abilities". |
| Source | Where the method comes from: tradition, author, where you trained. |
