# Карточка практики

Одна карточка — одна практика. Её читают гость, площадка и ты сам, когда собираешь сетку дней.

| Поле | Что написать |
|---|---|
| Название | Как практику зовут у тебя. |
| Формат | Группа, пара или соло. |
| Длительность на группу | Сколько минут занимает практика для всей группы, а не для одной пары. |
| Нагрузка | Низкая, средняя или высокая: дыхание, движение, эмоции. |
| Противопоказания | При чём практику не делают или делают облегчённо. Решение — за гостем и его врачом. |
| Касание | Есть или нет. Если есть — как спрашиваешь согласие и как гость может отказаться. |
| Что нужно | Зал, коврики, покрывала, музыка, свободное место. Кто что привозит: площадка / ведущий / гость. Запах, дым, громкий звук — есть или нет, как отказаться. |
| Что практика не обещает | Одна честная фраза: без «исцелит» и «откроет способности». |
| Источник | Откуда метод: традиция, автор, где ты учился. |
