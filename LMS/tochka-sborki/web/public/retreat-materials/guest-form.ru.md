# Анкета гостя ретрита

Заполни до заезда. Ответы видят только ведущий и, в части питания, кухня площадки.

## Контакты

1. Имя, как к тебе обращаться.
2. Телефон или мессенджер для связи в дороге.
3. Контакт на экстренный случай: имя и телефон.

## Питание

4. Как ты ешь: всё / без мяса и рыбы / веган / без глютена / веган без глютена / другое (опиши).
5. Аллергии на продукты. Насколько серьёзно: дискомфорт или опасно для жизни.
6. Чего ты не ешь по другим причинам.

## Практики

7. Есть ли ограничения по нагрузке, о которых ведущему стоит знать для безопасности на практиках? По желанию. Решение, подходит ли тебе практика, остаётся за тобой и твоим врачом.
8. Касание в практиках: да / нет / спрашивать каждый раз.

## Дорога

9. Рейс прибытия: номер, дата, время, аэропорт.
10. Рейс отъезда: номер, дата, время, аэропорт.
11. Нужна ли встреча в аэропорту.

## Прочее

12. Есть ли у тебя туристическая страховка на даты ретрита.
13. Согласие на фото и видео: да / только без лица / нет.
14. Что ещё нам стоит знать, чтобы тебе было хорошо.
