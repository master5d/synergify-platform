# Ф4 «Единый формат» — один контракт модуля/страницы на все курсы

**Дата:** 2026-08-08 · **Статус:** дизайн, решение по доменам принято владельцем
**Предпосылка (проверено кодом 2026-08-08, не по памяти):**

- Форматов сейчас **три**: (1) канон движка — `_meta.json` + `uN-*.mdx` + 4 фазы +
  MDX-компоненты (44 файла ТС используют `<Phase>`); (2) академия — TS-массивы прозы
  в `academy/lib/course/living-practice.ts` со своими `course-page`/`lesson-page`,
  MDX-стека в академии нет; (3) тренажёры — свой markdown-lite парсер.
- **Курс «Практика в живой связи» существует ДВАЖДЫ**: pack движка
  (`packs/living-practice`, 6 MDX-уроков, coming-soon) и проза академии (live на
  `/praktika`). Два источника правды уже разошлись разметкой.
- Фронтматтер юнита у обоих pack'ов ОДИНАКОВ (`title/unit/module/duration`) —
  расходятся только тела: фазы против прозы.
- `UnitWizard` рисует фазовую полосу **безусловно** (`PHASE_LABELS = t.phases`),
  а MDX кладёт внутрь целиком → prose-курс получает ложную шкалу 4 шагов.
- Курс-специфика в ядре: `MODULE_SLUGS` (спайн ТС; от него зависят quest-lines,
  quest-log, build-daily, lesson-prose, speech/course) и `lib/intake/questions.ts`.

## Решение владельца

`academy.synergify.com` **целиком становится проектом движка с путевым роутингом**:
школьная витрина и курсы живут на одном домене, курсы рендерит движок.

## Целевая топология

Проверенный в лабе паттерн (модель B из mc_hub: blog → hub через `merge-blog.mjs`):

1. `academy/` остаётся **школьной оболочкой**: главная, правила, гейт, тренажёры.
2. Курсы академии — **pack'и движка**, каждый собирается с `COURSE_BASE_PATH`
   (например `/praktika`) и мёржится в `academy/out/` при деплое.
3. Один CF Pages проект `synergify-academy` = оболочка + курсы. Домен один.

## Слайсы

- **S1 ✅ DONE — разметка урока становится свойством pack'а.** `_meta.json` получает
  `layout: "phases" | "prose"` (дефолт `phases` — обратная совместимость ТС).
  `unit-page`/`UnitWizard`: при `prose` фазовой полосы и пошагового мастера нет,
  проза рендерится целиком, завершение юнита остаётся. Гвард: ТС = phases,
  living-practice = prose; отсутствие ключа читается как phases.
- **S2 ✅ DONE — `COURSE_BASE_PATH`.** `next.config.ts`: `basePath` из env (пусто = как
  сейчас). Проверка: сборка LP под `/praktika` даёт рабочие внутренние ссылки.
- **S3 ✅ DONE — merge-деплой.** `scripts/merge-course.mjs` по образцу `merge-blog.mjs`:
  собрать оболочку → собрать pack с basePath → слить `out/` → один деплой.
  CI job `deploy-academy` делает оба билда и мёрж.
- **S4 ✅ DONE — убить дубль.** Снести `academy/lib/course/living-practice.ts`,
  academy-`course-page`/`lesson-page` и роуты `/praktika/*` из оболочки.
  ⚠ **Гейт**: сейчас admission-гейт живёт в академии, у движка уроки открыты.
  Перед сносом гейт переезжает в движок как свойство pack'а (`gated: true`) —
  иначе уроки школы откроются всем.
- **S5 — хвосты Ф1**: `MODULE_SLUGS` и `lib/intake/questions.ts` → в pack
  (`@pack/modules`, `@pack/intake`), иначе RPG-слой работает только для ТС
  (у LP сейчас 90 тестов в skip именно поэтому).
- **S6 ✅ соблюдено — тренажёры не тронуты**: это интерактивные приложения, а не контент;
  формат «модуль курса» на них не распространяется. Остаются в оболочке.

## Не в скоупе

Переписывание прозы «Практики» в фазы (это контент владельца); перевод тренажёров
в pack-формат; изменение домена `ai.synergify.com`.

## Критерии готовности эпика

Один формат контента (MDX + `_meta.json`) на все курсы платформы; `/praktika`
рендерится движком из pack'а под доменом академии; дубля курса нет; гейт цел;
`npm test` + оба билда + CI зелёные; живой смок обеих локалей.

## Что реально случилось (факт, 2026-08-08)

Коммиты: `aa91223` (S1 + починка резолвера), `a468735` (pageTitle), `c0926f2` (курс + S2/гейты),
`77a1d8e` (S3/S4 cutover). CI зелёный на каждом, живой смок пройден.

**Главная находка не была запланирована.** Переключатель `COURSE_PACK` оказался
декоративным с Ф1-S4: подпути `@pack/...` резолвятся через статичный tsconfig `paths`,
и ни turbopack-, ни webpack-алиас его не перебивали. Контент подменялся (fs-путь), а
словари/конфиг/данные молча приезжали от `tochka-sborki`. Тесты были зелены и честны —
у vitest свой резолвер, который env уважал. Нашлось рендером в браузере (заголовок
«…— Точка Сборки» у курса школы) и доказано экспериментом: уникальный маркер в
`course.config` не доехал до сборки. Фикс — `packs/_active` + гвард + CI-проверка бренда.

**Второе, что нашёл только рендер:** курс медитации показывал RPG-обвес (режимы
прохождения, шарды) — флаг `features.rpg` был проведён в шапку, но не внутрь мастера.

**Курс переписан по существу** (владелец: задание было принято неверно): вместо мета-курса
о практике — сам курс, 8 шагов, фазовая разметка, ИИ как собеседник МЕЖДУ сессиями.
Deep research (`../research/2026-08-08-meditation-course-evidence.md`) опроверг премиссу
«ИИ вместо кураторов»; курс это признаёт вслух в седьмом шаге.
