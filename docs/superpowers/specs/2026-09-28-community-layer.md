## Что решено и чего не делаем

Работа — **связать, а не строить**. Платформа не заводит форум, чат, ленту или хранилище работ учеников.
Сообщество — Telegram-группа владельца; платформа только (1) показывает ссылки в нужных местах курса и академии,
(2) бот платформы один раз приглашает в группу в нужный момент, (3) записи живых встреч — ссылкой в урок.
Данные учеников в платформе не дублируются: ни участники группы, ни их сообщения, ни присланные работы у нас
не хранятся. Единственное, что пишет платформа, — факт «приглашение отправлено» (чтобы не слать второй раз)
и отказ ученика от приглашений.

## Данные pack'а: `packs/<pack>/course/community.ts` (стаб `lib/course/community.ts`)

```ts
interface CommunityData {
  enabled: boolean                         // выключатель поверхностей на сайте курса
  groupUrl: string                         // публичная ссылка или invite-ссылка группы; '' = нет
  courseTopicUrl: string                   // тема/ветка курса в группе; '' = groupUrl
  moduleTopics: Record<string, string>     // модуль → ветка модуля (делимся практикой); нет — блока нет
  recordings: Record<string, Recording[]>  // 'модуль/юнит' → записи живых встреч
  copy: { heading, intro, cta, shareHeading, shareBody, shareCta, recordingsHeading, note }  // Bi
}
```

Пустые значения гасят поверхность (паттерн office-hours: «рендерить тёмным при пустых данных»).

- **Точка Сборки:** `enabled: false`, все ссылки пустые — группу, темы и invite-ссылки даёт владелец.
- **Тишина:** `enabled: true`, `groupUrl = https://t.me/kundaliniRUs`, `courseTopicUrl = …/7823` — ссылки уже
  даны владельцем и опубликованы в u8/FAQ/экосистеме. `moduleTopics` пуст **намеренно**: у курса один модуль, его
  последний юнит u8 уже ведёт в тему с оговорками («не терапевтическая группа», «при кризисе — линия из u5»), а
  «поделиться результатом практики» для этого курса неуместно — в теме не разбирают чужой опыт.

## Поверхности сайта курса

| Где | Что | Условие |
|---|---|---|
| Главная курса («вход») | карточка «Сообщество курса»: intro + кнопка в тему курса | `enabled` и есть ссылка |
| `/alumni` | та же карточка сверху — пространство **во время** учёбы поверх слоя выпускников | то же |
| Последний юнит модуля | «Покажи результат практики» — лёгкий peer review: выложить результат в ветку модуля, ответить двоим соученикам; работы живут в группе, не у нас | `enabled` и `moduleTopics[модуль]` |
| Юнит с записью встречи | «Записи живых встреч» — список ссылок | `enabled` и `recordings['модуль/юнит']` |

Страница академии (`academy.synergify.com`) — раздел «Сообщество» со ссылкой на чат академии; пустая ссылка
в словаре академии гасит раздел.

## Бот: приглашение (workers)

- Конфиг — `workers/src/lib/community.ts`: `COMMUNITY_INVITES` по месту приглашения: ключ курса
  (`progress.course`) и `academy`. Ссылки курса сверены тестом с данными pack'а (дрейф ловится в CI).
  `tochka-sborki` — пусто; `living-practice` — тема «Тишина»; `academy` — чат «Мастерская Перехода».
- Главный выключатель — `COMMUNITY_INVITES_ENABLED` (wrangler var, `"0"`). Приглашение — сообщение наружу,
  включает владелец.
- **Моменты:** (1) первый завершённый урок курса → приглашение в группу/тему курса (`handleComplete`, мимо ответа,
  best-effort); (2) новый допуск в академию (`handleAdmission`, только при первой выдаче) → приглашение в чат академии.
- **Один раз:** таблица `community_invites (user_id, place, trigger, sent_at, PK(user_id, place))`; строка
  захватывается `INSERT OR IGNORE` ДО отправки и снимается, если Telegram сообщение не принял.
- **Не шлём:** флаг выключен; ссылки места нет; у ученика нет `telegram_id`; `nudge_optout = 1` (`/stop` —
  «бот, молчи»); `community_optout = 1`. В этих случаях строка не захватывается.
- **Отказ:** под приглашением кнопка «Не присылать такое» (callback `community_off`) → `users.community_optout = 1`.
  `/start` его не сбрасывает (это про напоминания). Команда `/community` отдаёт ссылки по запросу всегда —
  это ответ на просьбу, а не рассылка.
- Тексты RU/EN — `bot-copy.ts`; кнопка-ссылка — url-кнопка (не `web_app`: t.me не мини-приложение).

Миграция `workers/migrations/0021_community_invites.sql` (additive) — к prod D1 применяет владелец.

## Когорты, модули, записи

Темы под когорты — данные владельца: когорты в платформе нет (Ф2), поэтому ветка когорты сейчас = тема курса.
Ветки модулей — `moduleTopics`. Записи встреч — `recordings`. Всё заполняется правкой данных pack'а, без кода.
