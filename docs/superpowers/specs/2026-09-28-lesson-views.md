# LMS: несколько представлений урока из одного источника — спека

Дата: 2026-09-28. Источник: intake LMS#8 (Google Learn Your Way, arXiv 2509.13348), строка BACKLOG
«LMS: несколько представлений урока из одного источника», **принято владельцем 2026-09-14**. Спека до кода.

## Зачем

Learn Your Way показывает одну главу в пяти видах: исходник, текст, слайды с озвучкой, аудиоурок, mindmap.
Ученик выбирает вид вкладкой. У нас юнит — один MDX, и прочитать его можно только одним способом.
Берём идею, а не продукт. **Источник правды — MDX юнита.** Все остальные виды выводятся из него и никогда
не правятся как самостоятельный текст.

## Что НЕ делаем в этой волне

- **Рантайм-LLM на каждый показ не делаем.** Виды считаются заранее и коммитятся как данные pack'а.
- **Аудио не генерируем.** Для озвучки нужен сервис вне lms-engine: TTS зверя через `NAUTILUS/core/voice`
  (`narrate`). Тащить его в эту волну нельзя, поэтому в схеме есть слот `audio: null` и описан путь ниже.
- **Видео не трогаем.** Это LMS#6 (video-fab). Вкладку «видео» добавим, когда появится пилотный ролик.
- **Слайды не делаем.** Это отдельный рендер, у Google для него своя агентная цепочка.
- **LF-piece пока не источник.** BACKLOG предлагал брать виды из того же LF-piece, что и видео LMS#6. Пилота LMS#6
  ещё нет, а MDX юнита уже есть и уже прошёл вычитку. Поэтому источник — MDX. Если потом аудио или видео будут
  собираться из LF-piece, `sourceHash` так же привяжет их к версии MDX.

## Представления

| Вкладка | Откуда | Как получается |
|---|---|---|
| **Текст** (по умолчанию) | MDX | как сейчас: фазовый мастер или проза (`unitLayout`) |
| **Конспект** | концепт-фаза MDX | извлечение: заголовки `##`/`###` + тезисы (см. ниже) |
| **Карточки** | `checks` в `_meta.json` модуля | вопрос на лицевой стороне; на обороте верный ответ и объяснение |
| **Карта** | тот же outline, что и у конспекта | дерево: юнит → разделы → подразделы → тезисы, узлы сворачиваются |
| Аудио | — | слот `audio: null`, вкладки нет (см. «Аудио — следующий шаг») |

**Конспект и карта — один outline в двух раскладках.** Мы не заводим второй источник фактов ради карты.

### Правило извлечения (`extract-v1`, детерминированно)

1. Отбросить frontmatter и кодовые блоки ```` ``` ````. Взять тело `<Phase type="concept">`, а если его нет — весь юнит.
2. Заголовки `##` открывают раздел, `###` и `####` — подраздел внутри текущего раздела. Текст до первого заголовка
   попадает в раздел без заголовка.
3. Тезисы раздела — фрагменты `**…**` не короче трёх слов. Короткие метки вроде «Было:» или «Кто» пропускаются.
   Дубли убираются.
4. Если в разделе тезисов нет, берётся первое предложение первого прозаического абзаца. JSX-метки, таблицы,
   цитаты и списки абзацем не считаются.
5. Текст тезиса — дословный фрагмент источника без markdown-разметки. **Ничего не перефразируется.**

Правило бедное, но честное: всё, что ученик видит в конспекте, дословно есть в уроке. Если понадобится
«умный» конспект с перефразом, его делает оффлайн-скрипт через `llm-service` и гейтвей. Такие пункты ложатся
в тот же артефакт с `origin: "manual"` (ручные) или `origin: "llm"` (зарезервировано). Для них действует
числовой гвард (ниже), а не дословный. В этой волне таких пунктов нет.

## Артефакт

Файл `packs/<pack>/views/<locale>/<module>/<unit>.json`, коммитится вместе с MDX:

```json
{
  "schema": 1,
  "generator": "extract-v1",
  "module": "01-introduction", "unit": "u2-four-shifts", "locale": "ru",
  "title": "Четыре сдвига",
  "sourceHash": "sha256:…",
  "outline": [{ "heading": "…", "points": [{ "text": "…", "origin": "extract" }], "children": [] }],
  "cards": ["c4", "c5"],
  "audio": null
}
```

`sourceHash` — sha256 от MDX юнита (концы строк нормализованы в LF) и JSON самопроверок этого юнита.
Правка урока или его вопросов меняет хэш.

Генератор: `node scripts/gen-lesson-views.ts [pack] [module]`. Работает на нативном type stripping Node,
без новых зависимостей. Без аргументов он пересобирает все существующие артефакты всех pack'ов, так чинится
устаревание. С аргументами — создаёт артефакты для всех юнитов модуля в обеих локалях. Файл, где есть пункты
с `origin` ≠ `extract`, без `--force` не перезаписывается.

## Гварды (`lib/lesson-views/views.test.ts`, активный pack)

- Артефакт ссылается на существующий юнит: модуль и юнит есть в `_meta.json` той же локали, а `title` совпадает.
- **Устаревание:** `sourceHash` равен хэшу текущего MDX и вопросов. Иначе тест падает с командой пересборки.
- Пункт с `origin: "extract"` (заголовок или тезис) дословно есть в источнике после снятия разметки.
- Пункт с другим `origin` (ручной): каждое число в нём есть в источнике, новых URL нет.
- `cards` — это ровно id самопроверок юнита из `_meta.json`, и они существуют.
- У каждого артефакта RU есть парный EN.
- `audio` пока равно `null` (слот зарезервирован).
- Детерминизм: повторное извлечение из того же MDX даёт тот же outline, а сам артефакт равен свежему извлечению.

Дополнительно, во время сборки: если хэш не совпал, загрузчик (`lib/lesson-views/load.ts`) не показывает вкладки
и пишет предупреждение. Устаревший вид до ученика не доходит, даже если тест кто-то пропустил.

## Что видит ученик

Над юнитом появляется переключатель «Текст · Конспект · Карточки · Карта» (EN: Text · Summary · Cards · Map).
Он виден, только если у юнита есть артефакт. По умолчанию открыт «Текст». Выбор не сохраняется и в аналитику
не уходит. Текстовый вид при переключении не размонтируется (`hidden`), поэтому шаг мастера и ответы
самопроверок не сбрасываются. Вкладка «Карточки» не показывается, если у юнита нет вопросов.

Доступность: `role="tablist"`/`tab`/`tabpanel`, стрелки влево и вправо двигают фокус, у карточки кнопка
«Показать ответ» с `aria-expanded`, у карты узлы на `<details>`.

Страница юнита меняется одной обёрткой вокруг `Shell` в `components/pages/unit-page.tsx`. Всё остальное живёт
в своём компоненте `components/lesson-views.tsx`.

## Аудио — следующий шаг (не в этой волне)

1. Текст озвучки — конспект (outline) или полный концепт-блок, по решению владельца.
2. Озвучка — `NAUTILUS/core/voice` (TTS зверя, `narrate`) оффлайн: mp3 + VTT на RU и EN.
3. Хранение — R2 или YouTube, mp4 и mp3 в git публичного репо не кладём (как в LMS#6).
4. Слот `audio: { src, transcript, sourceHash }`: свой хэш, чтобы озвучка устаревала вместе с текстом.
   Вкладка «Аудио» — через существующий `components/media-transcript.tsx`.

## Пилот

ТС `01-introduction` (4 юнита) и `living-practice` `01-living-practice` (8 юнитов), обе локали: 24 артефакта.
Расширение на весь курс — одна команда генератора на модуль. Решает владелец после просмотра пилота.

## Цена

Тесты и загрузчик только читают файлы. Сеть и LLM не нужны, на сборку это не влияет.
Цена для авторов: правка MDX пилотного юнита требует `node scripts/gen-lesson-views.ts`, иначе тест красный.
Это и есть смысл гварда.
