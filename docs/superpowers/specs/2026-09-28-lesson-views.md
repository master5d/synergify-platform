# LMS: несколько представлений урока из одного источника — спека

Дата: 2026-09-28. Источник: intake LMS#8 (Google Learn Your Way, arXiv 2509.13348), строка BACKLOG
«LMS: несколько представлений урока из одного источника», **принято владельцем 2026-09-14**. Спека до кода.

## Зачем

Learn Your Way показывает одну главу в пяти видах: исходник, текст, слайды с озвучкой, аудиоурок, mindmap.
Ученик выбирает вид вкладкой. У нас юнит — один MDX, и прочитать его можно только одним способом.
Берём идею, а не продукт. **Источник правды — MDX юнита.** Все остальные виды выводятся из него и никогда
не правятся как самостоятельный текст.

## Что НЕ делаем в этой волне

- **Рантайм-LLM на каждый показ не делаем.** Виды считаются заранее и коммитятся как данные pack'а
  (пересказ конспекта — тоже оффлайн, см. «Пересказ»).
- **Аудио не генерируем.** Для озвучки нужен сервис вне lms-engine: TTS зверя через `NAUTILUS/core/voice`
  (`narrate`). Тащить его в эту волну нельзя, поэтому в схеме есть слот `audio: null` и описан путь ниже.
- **Видео не трогаем.** Это LMS#6 (video-fab). Вкладку «видео» добавим, когда появится пилотный ролик.
- **Слайды не делаем.** Это отдельный рендер, у Google для него своя агентная цепочка.
- **LF-piece пока не источник.** BACKLOG предлагал брать виды из того же LF-piece, что и видео LMS#6. Пилота LMS#6
  ещё нет, а MDX юнита уже есть и уже прошёл вычитку. Поэтому источник — MDX. Если потом аудио или видео будут
  собираться из LF-piece, `sourceHash` так же привяжет их к версии MDX.

## Представления

| Вкладка | Откуда | Как получается |
|---|---|---|
| **Текст** (по умолчанию) | MDX | как сейчас: фазовый мастер или проза (`unitLayout`) |
| **Конспект** | концепт-фаза MDX | извлечение: заголовки `##`/`###` + тезисы (см. ниже); по умолчанию — пересказ тезисов, если он прошёл гвард, кнопка «Показать дословно» |
| **Карточки** | `checks` в `_meta.json` модуля | вопрос на лицевой стороне; на обороте верный ответ и объяснение |
| **Карта** | тот же outline, что и у конспекта | дерево: юнит → разделы → подразделы → тезисы, узлы сворачиваются |
| Аудио | — | слот `audio: null`, вкладки нет (см. «Аудио — следующий шаг») |

**Конспект и карта — один outline в двух раскладках.** Мы не заводим второй источник фактов ради карты.

### Правило извлечения (`extract-v2`, детерминированно)

1. Отбросить frontmatter и кодовые блоки ```` ``` ````. Взять тело `<Phase type="concept">`, а если его нет — весь юнит.
2. Заголовки `##` открывают раздел, `###` и `####` — подраздел внутри текущего раздела. Текст до первого заголовка
   попадает в раздел без заголовка.
3. Тезисы раздела — фрагменты `**…**` не короче трёх слов. Короткие метки вроде «Было:» или «Кто» пропускаются.
   Дубли убираются.
4. Если в разделе тезисов нет, берётся первое предложение первого прозаического абзаца. JSX-метки, таблицы,
   цитаты и списки абзацем не считаются.
   *(v2, 2026-09-28)* Если законченного предложения нет, берётся вводная фраза перед кодом/таблицей/списком
   («…у каждого свои стороны:») без двоеточия — не короче трёх слов. Без этого шага пять юнитов ТС, где проза
   раздела — одна такая фраза, оставались без единого тезиса.
5. Текст тезиса — дословный фрагмент источника без markdown-разметки. **Ничего не перефразируется.**
6. Юнит, у которого после шагов 1–4 нет ни одного тезиса (концепт-фаза — только шаблон в коде), артефакта
   не получает: генератор печатает `EMPTY` и удаляет старый файл, вкладок у такого юнита нет.

Правило бедное, но честное: всё, что ученик видит в конспекте дословно, есть в уроке. Связный пересказ
тезисов делает оффлайн-скрипт через гейтвей (раздел «Пересказ») и кладёт его в отдельный блок артефакта,
а не в `outline`. Ручные пункты (`origin: "manual"`) по-прежнему возможны прямо в `outline`; для них действует
числовой гвард (ниже), а не дословный.

## Артефакт

Файл `packs/<pack>/views/<locale>/<module>/<unit>.json`, коммитится вместе с MDX:

```json
{
  "schema": 1,
  "generator": "extract-v2",
  "module": "01-introduction", "unit": "u2-four-shifts", "locale": "ru",
  "title": "Четыре сдвига",
  "sourceHash": "sha256:…",
  "outline": [{ "heading": "…", "points": [{ "text": "…", "origin": "extract" }], "children": [] }],
  "cards": ["c4", "c5"],
  "audio": null,
  "paraphrase": {
    "source": "paraphrase", "generator": "paraphrase-v1", "pool": "prose-pool",
    "sections": [{ "sourceHash": "sha256:…", "points": ["…", "…"] }]
  }
}
```

Блок `paraphrase` необязателен (нет ключа — нет блока).

`sourceHash` — sha256 от MDX юнита (концы строк нормализованы в LF) и JSON самопроверок этого юнита.
Правка урока или его вопросов меняет хэш.

Генератор: `node scripts/gen-lesson-views.ts [pack [module]]`. Работает на нативном type stripping Node,
без новых зависимостей (относительные импорты `lib/` без расширения ему подсказывает resolve-хук `registerHooks`).
Без аргументов он пересобирает все существующие артефакты всех pack'ов, так чинится устаревание. С `pack` —
создаёт артефакты всех юнитов всех модулей pack'а в обеих локалях, с `pack module` — одного модуля. Файл, где
есть пункты с `origin` ≠ `extract`, без `--force` не перезаписывается. Дословная часть детерминирована и сети
не требует; готовый пересказ при пересборке переносится по хэшу раздела (см. ниже).

## Гварды (`lib/lesson-views/views.test.ts`, активный pack)

- Артефакт ссылается на существующий юнит: модуль и юнит есть в `_meta.json` той же локали, а `title` совпадает.
- **Устаревание:** `sourceHash` равен хэшу текущего MDX и вопросов. Иначе тест падает с командой пересборки.
- Пункт с `origin: "extract"` (заголовок или тезис) дословно есть в источнике после снятия разметки.
- Пункт с другим `origin` (ручной): каждое число в нём есть в источнике, новых URL нет.
- `cards` — это ровно id самопроверок юнита из `_meta.json`, и они существуют.
- У каждого артефакта RU есть парный EN.
- `audio` пока равно `null` (слот зарезервирован).
- Детерминизм: повторное извлечение из того же MDX даёт тот же outline, а сам артефакт (без блока `paraphrase`)
  равен свежему извлечению.
- **Пересказ:** блок помечен (`source: "paraphrase"`, генератор, пул `prose-pool`), каждый его раздел ссылается
  хэшем на раздел текущего outline и проходит гвард пересказа (см. «Пересказ»).

Дополнительно, во время сборки: если хэш не совпал, загрузчик (`lib/lesson-views/load.ts`) не показывает вкладки
и пишет предупреждение. Устаревший вид до ученика не доходит, даже если тест кто-то пропустил. Гвард пересказа
загрузчик прогоняет тоже: раздел, не прошедший его, ученик видит дословным.

## Что видит ученик

Над юнитом появляется переключатель «Текст · Конспект · Карточки · Карта» (EN: Text · Summary · Cards · Map).
Он виден, только если у юнита есть артефакт. По умолчанию открыт «Текст». Выбор не сохраняется и в аналитику
не уходит. Текстовый вид при переключении не размонтируется (`hidden`), поэтому шаг мастера и ответы
самопроверок не сбрасываются. Вкладка «Карточки» не показывается, если у юнита нет вопросов.

Доступность: `role="tablist"`/`tab`/`tabpanel`, стрелки влево и вправо двигают фокус, у карточки кнопка
«Показать ответ» с `aria-expanded`, у карты узлы на `<details>`.

Страница юнита меняется одной обёрткой вокруг `Shell` в `components/pages/unit-page.tsx`. Всё остальное живёт
в своём компоненте `components/lesson-views.tsx`.

Во вкладке «Конспект» по умолчанию показан пересказ (если у юнита есть хотя бы один раздел с годным пересказом;
остальные разделы — дословно). Подпись честно говорит, что текст написала модель и что проверено. Кнопка
«Показать дословно» / «Показать пересказ» (`aria-pressed`) — как «Показать общий пример» у примера из интереса.
«Карта» всегда дословная.

## Пересказ (решение владельца 2026-09-28: «пересказ через prose-pool»)

Дословные тезисы читаются рвано: это выдернутые из абзацев фразы. Пересказ переписывает тезисы раздела
в 1–4 связных коротких пункта на языке юнита. Модель видит **только** заголовок и тезисы раздела, а не весь
урок, поэтому добавить ей нечего.

- **Команда:** `node scripts/gen-lesson-views.ts <pack> [module] --paraphrase` — сначала обычное извлечение,
  потом пересказ разделов, у которых его ещё нет (`--refresh` — всех заново, `--report <file>` — все ответы
  с вердиктом гварда для вычитки). Вызов — на пачку до трёх разделов юнита (JSON-запрос): на длинном юните рассуждение пула иначе съедает бюджет до конца ответа.
- **Гейтвей:** `LITELLM_URL` (по умолчанию `https://sovrn-mini.taile5b8dd.ts.net/v1`), `POST /chat/completions`,
  `model: "prose-pool"` (алиас пула, не имя модели), заголовок `x-sovern-agent: lms-lesson-views`, ключ —
  `LITELLM_KEY` из окружения (не печатается). Таймаут 120 с на вызов, `max_tokens` 12000 (пул «думает», малый
  бюджет даёт пустой `content`), параллелизм 4, на 429/5xx — пауза по `retry-after` или экспоненциально,
  до 5 попыток; пустой/не-JSON ответ — до 3 повторов.
- **Хранение:** блок `paraphrase` артефакта; каждый раздел несёт `sourceHash` — sha256 заголовка и дословных
  тезисов, т. е. ровно того, что видела модель. Пересборка переносит пересказ раздела, пока этот хэш совпадает
  с разделом нового outline; изменился раздел — его пересказ выпадает (`STALE …` в выводе), остальные живут.
  Поэтому правка другого места урока (активация, вопросы) пересказ не сбрасывает, а дословная часть остаётся
  детерминированной — её генерация не зависит от сети.
- **Гвард** (`lib/lesson-views/paraphrase.ts`, `checkParaphraseSection`), сверка с исходным MDX юнита:
  числа, URL, инлайн-код — только те, что есть в уроке; имена инструментов/команд/файлов — латинская лексема
  в RU-пункте и «похожее на имя» в EN-пункте (CamelCase, КАПС, точка/слэш/цифра, заглавная не в начале
  фразы) обязаны встречаться в уроке; язык (в EN нет кириллицы, в RU есть); без markdown; на «вы», если
  этой формы нет в уроке, — отказ (голос курса — «ты»); 3–40 слов и ≤ 240 знаков на пункт, 1–5 пунктов,
  весь раздел не длиннее 1,5 × дословного + 200 знаков; манифест pack'а и de-hustle. Хоть одна находка —
  раздел остаётся дословным. Гвард пересказа проверяет, что в нём **нет нового**, но не может проверить,
  что смысл передан верно. Это делает вычитка по `--report`.
- **Деградация:** нет `LITELLM_KEY` — «ПЕРЕСКАЗА НЕТ», артефакты дословные, exit 3. Транспортный отказ или
  пустой ответ после повторов — `GATEWAY …`/`NO-PARAPHRASE …`, «ПЕРЕСКАЗ НЕПОЛНЫЙ», exit 3. Отказ гварда —
  не ошибка: раздел честно дословный, счёт отказов по причинам печатается.

## Аудио — следующий шаг (не в этой волне)

1. Текст озвучки — конспект (outline) или полный концепт-блок, по решению владельца.
2. Озвучка — `NAUTILUS/core/voice` (TTS зверя, `narrate`) оффлайн: mp3 + VTT на RU и EN.
3. Хранение — R2 или YouTube, mp4 и mp3 в git публичного репо не кладём (как в LMS#6).
4. Слот `audio: { src, transcript, sourceHash }`: свой хэш, чтобы озвучка устаревала вместе с текстом.
   Вкладка «Аудио» — через существующий `components/media-transcript.tsx`.

## Цена

Тесты и загрузчик только читают файлы. Сеть и LLM не нужны, на сборку это не влияет.
Цена для авторов: правка MDX любого юнита требует `node scripts/gen-lesson-views.ts`, иначе тест красный.
Это и есть смысл гварда. Пересказ изменённого раздела выпадает до следующего `--paraphrase` — раздел до тех
пор показывается дословно, тест при этом зелёный.
