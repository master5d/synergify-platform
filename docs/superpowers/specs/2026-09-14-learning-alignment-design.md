## Решения владельца

| Вопрос | Решение |
| --- | --- |
| Кто пишет цели и вопросы существующих курсов | Черновик — агент по тексту уроков → piece в Logos Foundry → утверждение владельца (A) |
| «Проверь себя» в «Тишине» | Только понимание рамки и безопасности курса (потолок, стоп-сигналы, чего компаньон не делает); про личный опыт вопросов с «правильным ответом» нет; компонент один (A) |

| Где живут вопросы | В `_meta.json` модуля рядом с целями; в уроке только метка места (2) |

## 1. Контракт `_meta.json`

Каждый `_meta.json` модуля каждого pack'а (RU и EN) несёт:

```json
"objectives": [
  { "id": "o1", "text": "Отличить первоисточник от упаковки по трём признакам" }
],
"checks": [
  { "id": "c1", "unit": "u4-sources", "objective": "o1",
    "question": "…", "options": ["…", "…", "…"], "answer": 1, "explain": "…" }
]
```

- `objectives`: 3–5 проверяемых целей; `id` уникальны в модуле.
- `checks`: `unit` — slug урока этого модуля; `objective` — id цели этого модуля; `options` 2–5;
  `answer` — индекс правильного варианта (0-based); `explain` — объяснение, почему так.
- В MDX урока: `<SelfCheck id="c1"/>` — место вопроса (обычно после концепт-блока).
- Типы — в `ModuleMeta` (`lib/content.ts`), поля опциональны в типе, обязательность держит гвард.

## 2. Гвард `lib/content/alignment.test.ts`

Прогоняется для активного pack'а (`npm test`, матрица build-packs). Красный, если:

1. модуль не 3–5 целей, повтор id цели, пустой текст или заглушка (`TODO`, `…`, `TBD`);
2. вопрос ссылается на несуществующие цель/урок; вариантов < 2 или > 5; `answer` вне диапазона;
   пустые `question`/`explain`/вариант или заглушка;
3. **цель без единого вопроса** (висящая цель, Биггс 1996);
4. метка `<SelfCheck id>` не совпадает с `checks`: каждый вопрос размечен ровно один раз и в своём
   `unit`; неизвестный id в MDX; метка вне урока (cheatsheet/exercises/roadmap);
5. RU/EN расходятся: разные наборы id целей или вопросов, разный `unit`/`objective`/`answer` у одного id.

Не проверяет: вопрос в каждом уроке (покрываются цели модуля); «глагол действия» в цели — смысловой
критерий подпроекта 2.

**Храповик раскатки `PENDING_ALIGNMENT`** (не ослабление): явный список модулей pack'а, ещё не
получивших тексты. Тест: модуль вне списка без целей — красный; модуль в списке, уже имеющий цели, —
красный (убрать из списка); список ⊆ зафиксированного снимка (новый модуль туда не спрятать). Пустой
список удаляется вместе с кодом.

## 3. Отображение

- **Цели модуля** — блок «Цели модуля» / «Module goals» в начале **первого** урока модуля, обе
  оболочки (`UnitWizard`, `UnitProse`); стиль — врезка цели из `lesson-prose.tsx` (тонкая линия
  слева, приглушённый цвет). Отдельной страницы модуля нет (`ModuleRedirect` ведёт на урок).
- **Дерево курса** (`syllabus-tree.tsx`) — свёрнутый `<details>` «Цели» под описанием модуля.
- **`SelfCheck`**: `unit-page.tsx` уже читает `moduleMeta` на сервере и передаёт в `MDXRemote`
  `components={{ ...mdxComponents, SelfCheck }}`, где `SelfCheck` берёт вопрос по id из
  `moduleMeta.checks` (без провайдера и клиентской загрузки). Клиентская часть: `fieldset`/`legend`,
  радио, «Проверить» → правильный вариант + объяснение, объявление через `aria-live`; попытки без
  лимита; событие Plausible `self_check_answered {module, unit, objective, correct}` — один раз на вопрос за просмотр страницы, no-op без `window.plausible`.
  Токены дизайна — как у блока компаньона. Подпись «Проверь себя» / «Check yourself».
- Нет: таймеров, баллов, хранения ответов, интервального повторения.

## 4. Авторинг

- `module-scaffold` / `author-module` ставят поля `objectives` и `checks`; `objective` из outline
  (`course-plan-prompt`) — первая цель. Заглушки скаффолда гвард не пропустит.
- `LMS/_template/CHECKLIST.md` §5a: пункт «цели и вопросы модуля».
- Тексты существующих курсов: агент пишет черновик по урокам → piece в Logos Foundry на курс
  (markdown-таблица: цели, вопросы, варианты, ответ, объяснение, урок) → редколлегия → утверждение
  владельца → перенос в RU `_meta.json`; EN — перевод LF (подпроект H) → EN `_meta.json`.

## 5. Порядок

1. Движок + гвард + храповик (ТС: 10 модулей в `PENDING_ALIGNMENT`) + утверждённые тексты «Тишины»
   (1 модуль) — одним изменением.
2. Точка Сборки — партиями модулей по мере утверждения; каждая партия вычёркивает свои модули из списка.
3. Список пуст → удалить храповик.

## 6. Тесты и критерий готовности

- `SelfCheck`: рендер, верный/неверный ответ, объяснение, событие ровно один раз.
- Блок целей: только первый урок модуля, обе оболочки.
- Гвард: мутационные фикстуры — каждое из пяти правил и три правила храповика краснеют на своей поломке.
- Оба pack'а: `npm test`, `tsc --noEmit`, `npm run build`; живой урок «Тишины» показывает цели и вопрос.
