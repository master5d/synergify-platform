# Учебные цепочки писем «Точки Сборки» — шаблоны Listmonk

Тексты писем живут здесь, в git, и заливаются в Listmonk как **tx-шаблоны** (`type: tx`) скриптом
`workers/scripts/sync_listmonk_templates.py`. После заливки их можно править в Listmonk UI, но источник
правды — этот каталог: следующая заливка перезапишет ручную правку.

Кому и когда слать, решает **оркестратор в воркере** (`workers/src/lib/email-chains.ts`, ежедневный cron
рядом с Telegram-напоминаниями). Listmonk только рендерит шаблон и отправляет письмо (`POST /api/tx`).
Встроенных drip-цепочек в Listmonk нет (v6.2), а tx-отправка сама не проверяет ни отписку, ни blocklist —
всё это делает оркестратор. Разбор: NAUTILUS `docs/superpowers/research/2026-09-27-course-email-lifecycle-listmonk.md`.

Приветствие в день 0 — не здесь: его шлёт `workers/src/lib/welcome-email.ts` сразу при регистрации.

## Цепочки

| Шаг (`step`) | Когда | Условие выхода |
|---|---|---|
| `start-1` | день 2 после регистрации, курс не начат | ученик открыл любой урок |
| `start-2` | день 5 после регистрации, курс не начат | то же; дальше цепочка молчит |
| `lapse-1` | 3 дня без активности, курс начат и не закончен | любая активность |
| `lapse-2` | 7 дней без активности | то же |
| `lapse-3` | 14 дней без активности — последнее, «пауза или отписка» | дальше молчим до новой активности |
| `milestone` | модуль целиком закрыт (событие `progress_events`, `kind='module'`) | — |
| `finish-1` | курс закрыт целиком (`kind='course'`) | — |
| `finish-2` | 7 дней после `finish-1` — приглашение в академию | — |

Общие правила оркестратора:
- не больше одного письма в день на человека;
- при совпадении приоритет `finish` > `milestone` > `lapse` > `start`;
- напоминания (`start`, `lapse`) не шлются, если ученик был активен в последние 20 часов;
- напоминания не шлются тем, кто привязал Telegram и не отказался от напоминаний там: канал один;
- `lapse`-эпизод начинается заново после новой активности (ключ шага включает день последней активности).

## Имена шаблонов

`ts-<step>-<lang>`, где `lang` — `ru` или `en`: `ts-start-1-ru`, `ts-milestone-en` и т. д. Всего 16.
Файл шаблона — `<имя>.html`; тема письма — первая строка файла в виде `<!-- subject: … -->`.

## Данные (`.Tx.Data`)

Во всех письмах:

| Поле | Что это |
|---|---|
| `course_name` | «Точка Сборки» / «Tochka Sborki» |
| `home_url` | главная курса на языке ученика |
| `unsubscribe_url` | отписка от учебных писем (страница с кнопкой; one-click POST — заголовок `List-Unsubscribe-Post`) |

По шагам:

| Шаг | Поля |
|---|---|
| `start-1` | `start_url` — первый юнит модуля 00 |
| `start-2` | `start_url` — юнит «Азбука» (`00-kickstart/u0-azbuka`) |
| `lapse-1` | `module_title`, `resume_url`, `done_modules`, `total_modules` |
| `lapse-2` | `module_title`, `resume_url`, `support_url` |
| `lapse-3` | `resume_url` |
| `milestone` | `module_title`, `next_title`, `next_url`, `done_modules`, `total_modules`, `from`, `to` (трансформация модуля); для последнего модуля спайна `next_title`/`next_url` пусты |
| `finish-1` | `certificate_url` |
| `finish-2` | `academy_url` (главная академии: вход открывается после Точки Сборки), `support_url` |

Поле, которого нет в данных, шаблон обязан пережить: необязательные блоки обёрнуты в `{{ if .Tx.Data.x }}`.
